## 阅读范围 / Scope

文档覆盖当前桌面客户端：本地 Agent、Linux 独立桌面及共享环境、Mac/Windows 本机控制、模型配置和工作资料管理。平台或后台版本不同，入口可能有所不同；示例是你可以提出的任务，不代表已经执行的结果。

The guide covers the current desktop client: the local agent, independent Linux desktops and their shared environment, native Mac/Windows control, model configuration, and work information. Availability can vary by platform or backend version. Example requests are suggestions, not claims of completed execution.

云端托管、手机端和跨设备实时同步仍属后续方向。网页 UI 预览不执行真实任务。工作区 JSON 导出不等于完整备份。

Hosted cloud execution, a mobile client, and live cross-device synchronization remain future directions. Web UI previews do not execute real tasks. Workspace JSON export is not a complete backup.
