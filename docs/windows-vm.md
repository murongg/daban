# Windows Linux 电脑

默认 Windows 安装包保持轻量。点击安装 Linux 电脑后，搭伴才按需下载约 1.6 GB 的 QEMU、Debian 13 x64、桌面、Chromium 和执行服务，无需另装虚拟机软件或填写连接参数。仅打开客户端、聊天或使用本机电脑不会下载虚拟机。

## 普通安装

1. 安装 Windows 客户端，打开搭伴并配置模型。在 Bot 的「电脑 → Linux 虚拟机」面板，或「设置 → 电脑权限」中点击「安装 Linux 电脑」。界面会显示下载大小、进度和所需空间，下载可暂停并继续。
2. 默认使用 QEMU + Windows Hypervisor Platform（WHPX）硬件加速。需要开启功能时，Windows 会请求管理员授权；应用只启用 `HypervisorPlatform`，不会自动重启电脑。
3. 系统要求重启时，先保存其他应用的工作。可点击「重启 Windows…」并确认，也可稍后自行重启。重启后打开搭伴，已请求且未暂停的安装会继续。功能已经可用时无需重启。
4. 不想重启时，展开「其他安装方式」，主动选择「使用兼容模式（较慢）」。它使用 QEMU TCG，桌面、浏览器和任务工具保持相同接口，但速度较慢、CPU 占用较高。应用不会静默切换加速方式。
5. 安装界面显示实际检查、解压、创建、启动和连接阶段。可暂停、继续或重试；重试保留现有磁盘和身份，不会覆盖任务文件或重复创建已启动的电脑。

运行时默认分配 4 个 CPU、6 GiB 内存和 64 GiB 动态虚拟磁盘。安装前界面检查当前磁盘空间；磁盘随后按实际使用增长。首次安装适用于 Intel/AMD x64 Windows；ARM64 环境包不在此实现范围内。

后台服务、VM 和已接受的 Linux 任务不依附客户端窗口。退出客户端撤销本机桌面授权，但不会关停 VM；休眠、Windows 重启和关机会中断本机执行。重启按钮会先通过后台的空闲检查，有任务、恢复操作或安装运行时拒绝重启。

QEMU 只将 SSH 和经过双向 TLS 认证的控制接口绑定到 Windows 回环地址。每次新安装生成独立 SSH 登录密钥、固定来宾主机公钥及控制证书；镜像不含登录凭据、浏览器状态或任务数据。模型和审批仍在 Windows，默认不共享 Windows 文件夹。

## 环境下载与发布

客户端及后台更新与 Linux 环境版本分开管理。同一环境的下载缓存可跨客户端升级复用；安装完成后，VM 使用自己的磁盘和工具，启动不依赖下载服务器或旧安装目录。下载失败时保留断点，继续时校验完整 SHA-256；校验失败的缓存会重新获取。解包只接受有大小限制的普通文件，禁止路径越界、链接和覆盖已有目录。旧的离线完整包仍可直接安装，不需要联网获取同一环境。

维护者先用 `tools/qemu-image.ts` 构建并封存干净镜像，再运行 `node --experimental-strip-types tools/qemu-release.ts build <封存环境目录> <新输出目录>`。输出只包括压缩镜像、固定 QEMU 工具、来源记录和许可证，不包含原始构建磁盘。验证后将生成的大小及摘要固定到 `packages/engine/src/qemu-reference.ts`，提交代码，再用 `qemu-release.ts publish <Daban-linux-windows-x64.zip> <提交 SHA>` 发布对应的独立环境预发布资源。相同摘要的资源不可覆盖；镜像有变更时创建新版本并重新验收。`qemu-release.ts verify` 检查公开资源与固定值一致，正式客户端发布流程会先执行此检查。
