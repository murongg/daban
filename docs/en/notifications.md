# Desktop notifications

[User guide](README.md) · [简体中文](../zh-CN/notifications.md)

Open **Settings → General → Desktop notifications** for background completion, failure, and attention-needed notices. Notifications do not display full task content.

## Enable and test

1. Enable desktop notifications.
2. Check that the operating system permits Daban notifications.
3. Send a test notification. This does not start a Bot task or submit an approval.
4. Choose per-Bot private-conversation notification settings when needed.

The master switch suppresses delivery without forgetting per-Bot selections. Disabling private notices for one Bot does not disable group notices or remove Inbox requests.

## Open a notice

Click a notification to open the relevant request or result when available. If navigation fails, inspect the [Inbox](inbox.md), conversation, or history. Notification wording alone does not prove successful execution.

Notices identify the event type rather than revealing the complete task or question. The notification center is not the full task record.

## Missing notifications

- OS permissions, Do Not Disturb, focus modes, and display preferences affect delivery.
- Test in the desktop client; web previews do not request system notification permission.
- Use Inbox and conversation records when the backend or client version lacks support.
- Fully quitting stops discovery of new notices, even when Linux background work continues. Reopen to inspect results.

Settings apply to this computer. This feature is not mobile push or a cross-device notification service.
