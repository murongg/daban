# Create and manage Bots

[User guide](README.md) · [简体中文](../zh-CN/bots.md)

A Bot is a persistent working companion with its own profile, private conversation, preferences, knowledge, notes, and schedules. It is not an exclusive virtual machine.

## Create a Bot

1. Use the new-Bot button at the top of the sidebar or the plus button beside your Bots.
2. Enter a name, choose an avatar color, and describe its responsibilities. You can also start from the [Bot gallery](gallery.md).
3. Follow the workspace model or select a configured model.
4. Save and start a conversation. Connect a computer only when graphical interaction is needed.

A useful role describes the goal, output, and working style: “Help organize business documents; lead with conclusions and sources; ask when information is missing.” Role instructions do not grant tool or computer permissions.

You can also ask “Create a Bot to organize reference material.” The built-in [bot-manager skill](skills.md#built-in-bot-manager) saves a new assistant in the sidebar, following the workspace model with empty private memory.

## Edit a Bot

Open **Edit Bot profile** in the conversation header to change its name, role, and model. Role and model changes apply to future tasks, not work already underway. Avatar colors distinguish companions rather than capability levels.

Concurrent updates may produce a revision conflict. Review the saved content before retaining your own edits and saving again; do not overwrite changes you have not reviewed.

## Copy, share, or put aside

- Use [Copy a Bot](copy-bot.md) to create another companion with the same saved role.
- Use [Bot import and export](bot-transfer.md) to transfer selected preferences, reference documents, and skill instructions.
- Use [Archives](archives.md) to put a Bot aside without clearing chats or deleting the runtime.

Matching names do not imply matching identities. Copies and imports create new Bots and do not inherit the original conversation or desktop authorization.

## Data and computer boundaries

Private conversations, memory, and knowledge belong to each Bot. [Shared tasks](tasks.md) belong to the workspace. Linux Bots share files, installed software, and browser sign-ins; independent screens are not security isolation. See [Privacy and permissions](privacy.md).
