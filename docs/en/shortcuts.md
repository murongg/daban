# Shortcuts and icons

[User guide](README.md) · [简体中文](../zh-CN/shortcuts.md)

Shortcuts depend on focus and platform. A dialog, editor, or remote computer can handle keys locally instead of the main workspace.

| Action | Mac | Windows |
| --- | --- | --- |
| Search Bots and conversations | Cmd + K | Ctrl + K |
| Open settings | Cmd + , | Ctrl + , |
| Send message | Enter | Enter |
| New line in a message | Shift + Enter | Shift + Enter |
| Leave remote input focus | Escape | Escape |
| Send Escape remotely | Option / Alt + Escape | Alt + Escape |
| Pause real native computer input | Ctrl + Option + Esc | Ctrl + Alt + Esc |
| Open a focused Bot row menu | Menu button or Shift + F10 | Menu button, Shift + F10, or context-menu key |

Escape in the main workspace can close the sidebar or workspace panel. Most dialogs support Escape, subject to submitting/unconfirmed-operation states. Closing a dialog does not undo an action.

## Common icons

- Square stop: request cancellation of the current task, not deletion of its record.
- Diagonal expand: enlarge a desktop or browser view.
- Refresh: read current state again, not rerun historical tasks.
- Ellipsis/organization menu: actions for the current Bot, group, or section.
- Lock: protect schedule edits, not enable or pause execution.

Hover or keyboard focus reveals most icon labels. Complete input-method composition before sending text. Use the remote text field when composed input does not work instead of repeatedly sending keystrokes.

Pausing native input, stopping a model task, stopping a Bot computer, and recovering Linux are different actions. See [Native control](local-computer.md), [Execution](execution.md), [Linux computers](linux-computer.md), and [Recovery](recovery.md).
