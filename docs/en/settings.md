# Settings and interface preferences

[User guide](README.md) · [简体中文](../zh-CN/settings.md)

Open the sidebar settings button or press Cmd + , / Ctrl + ,. Settings appear in a dialog with categories on the left and their controls on the right.

## Categories

| Category | Contents |
| --- | --- |
| General | Light/dark appearance, interface language, notifications |
| Models & providers | Connections, lists, testing, capabilities, default model |
| Computer & permissions | Connectivity, OS permissions, Linux diagnostics and recovery |
| External tools | MCP connections and per-Bot tool selection |
| Archives | Archived Bots and groups |
| Conversation trash | Restore conversations moved out of recent conversations |
| Data & storage | Client data scope and workspace export |
| About | Version and capability boundaries |

Unavailable items may be hidden by platform or backend version. Windows native mode does not show full Linux diagnostics and restart controls.

## Appearance and language

Choose light or dark appearance in General. Switch immediately between Simplified Chinese and English; the choice is saved on this device.

Interface language changes application text, not your Bot names, documents, messages, or model replies. Ask the Bot for another response language in conversation or [Memory](memory.md).

## Saving and closing

Some preferences take effect immediately. Model and external-connection forms need their own save action. Visible editor content is not proof it has been saved; follow the form's status.

Unsubmitted keys are not retained as saved configuration. Save needed form content before closing settings, restarting, or reloading. If a submitted operation is unconfirmed, verify that original request instead of filling out another one.

Models, tools, OS permissions, and desktop control have separate scopes. See [Models](models.md), [External tools](integrations.md), and [Native desktop](local-computer.md). Daban remains an early preview; public-distribution signing, notarization, and a complete automatic-update flow are still being developed.
