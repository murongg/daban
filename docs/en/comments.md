# Task discussions and comments

[User guide](README.md) · [简体中文](../zh-CN/comments.md)

Open a [shared task](tasks.md) and select its discussion. Comments belong to that task and are shared with you and all Bots.

## Post a comment

1. Review the task's current title, description, and state.
2. Read existing discussion and load earlier comments if needed.
3. Enter additional information or progress, then post. A comment can contain up to 10,000 characters.
4. Confirm that the new comment appears before continuing.

Example: “The delivery date was confirmed for next Friday; this is a progress note, not a request to start work.” You can explicitly ask a Bot to add a comment to a specific task.

## A comment is not a dispatch

Posting does not start a Bot, create a schedule, change task fields, or grant tool permissions. Request execution or state changes separately. Other discussion content is also reference data.

## Uncertain results

- Discussion remains readable when a task is trashed. Restore the task before posting more.
- Verify an unconfirmed task save before adding a comment.
- Use the comment-result verification action when posting is uncertain. Retry that same comment through its existing action rather than posting another copy.
- Draft text can remain available during recovery; submit after recovery completes.

The discussion preserves textual progress. Do not assume it provides a complete human team-membership system, instant-message notifications, or arbitrary editing and deletion of historical comments.
