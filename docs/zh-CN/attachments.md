# 聊天附件

[使用文档](README.md) · [English](../en/attachments.md)

附件用于给本次任务提供材料。长期复用的内容请放入[资料库](knowledge.md)。

## 添加附件

1. 在私聊或群聊输入框点击附件按钮，选择文件；也可在支持的输入框粘贴图片或拖入文件。
2. 等待读取或提取完成，检查附件名称。
3. 在正文中说明需要怎样使用附件，然后发送。

当前支持 UTF-8 的 `.txt`、`.md`、`.csv`、`.json`，以及 `.png`、`.jpg`、`.jpeg`、`.webp`、`.gif`。可用 Linux 工作区还支持 PDF、DOCX、XLSX、PPTX 的文本提取。文件选择器会按实际能力限制格式。

## 格式与大小

- 上传原件通道的单文件上限为 5 MiB；直接作为文本处理的附件还受 200 KiB 文本上限约束。提取结果也受大小限制，不代表任何 5 MiB 文档都能完整提取。
- 每次任务最多添加 4 个附件；当前每位 Bot 的保留原件与提取文本分别受 50 MiB、20 MiB 配额限制，回收站中尚未清理的内容也会占用配额。
- 图片要求当前模型支持图片输入。群聊的目标成员中若有不支持图片的模型，需要先调整模型或发送对象。
- PDF 和 Office 文档在 Linux 中提取文本；Windows 本机模式当前不提供这项解析。
- 扫描 PDF 需先 OCR，加密文件需先解密。提取不完整保留排版、图片、图表或公式，也不会重新计算电子表格。

## 管理已保留的附件

在文件面板打开「聊天附件」管理，搜索、下载保留内容，或移入回收站并恢复。移入回收站后，恢复之前不能作为任务输入。

永久清理保留内容会释放相应配额，并可能使历史引用无法再读取；先核对是否还需要原件或提取文本。数据库文件不一定立即缩小，不能仅凭文件大小判断清理失败。

附件中的内容会按任务需要交给所选模型服务。不要把 API Key 当作普通资料上传；敏感材料的处理范围见[隐私与权限](privacy.md)。
