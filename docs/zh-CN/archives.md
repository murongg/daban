# 归档与恢复 Bot / 群聊

[使用文档](README.md) · [English](../en/archives.md)

归档用于暂时收起对象并停止接受新工作。管理入口：**设置 → 归档管理**。

## 归档 Bot

1. 先结束正在进行的任务和相关未完成协作。
2. 保存电脑应用里的内容，停止这位 Bot 的电脑。
3. 在侧栏 Bot 行菜单或 Bot 资料中选择「归档 Bot」，检查影响后确认。
4. 在归档管理中核对状态，需要时查看历史。

归档保留聊天、草稿及相关资料，不是永久删除。自动任务会受影响，恢复后需要检查并手动重新启用；恢复不会重新授予本机电脑或外部工具的旧权限。

## 归档群聊

先结束该群正在进行的协作，再从群聊的归档入口操作。成员、历史、附件、文件和未发送草稿保留；成员的独立私聊与电脑不受群聊归档影响。

恢复群聊只是恢复入口，不会自动重新派发以前的消息。

## 恢复或核对

打开归档管理，选择 Bot 或群聊恢复。操作状态不明时，先使用核对操作的入口读取原回执；关闭窗口不会撤销已提交动作。

对象已被其他窗口修改时，核对当前资料状态，不要把一次旧归档的结果强行覆盖到新状态上。

## 与回收站的区别

对话可从最近对话或右上方菜单移入回收站，并在 **设置 → 对话回收站** 恢复，见[聊天与历史对话](conversations.md)。

资料、技能、便笺、共享任务、附件和外部连接各有对应的回收站或归档入口，不都集中在这里。它们的恢复和权限规则请看各自功能文档。

归档不删除 VM，也不等于清理磁盘、退出浏览器账号或擦除历史。环境异常时见[恢复](recovery.md)，需要留存时见[导出](workspace-export.md)。
