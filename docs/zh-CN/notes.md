# Bot 便笺

[使用文档](README.md) · [English](../en/notes.md)

入口：选择 Bot，打开 **便笺** 面板。便笺只供这位 Bot 和你使用，适合记录零散事项和想法。

## 创建和跟进

1. 点击「新建便笺」。
2. 填写标题、正文和状态，保存。
3. 使用搜索与筛选找回事项，按需调整为待处理、暂存或已完成。
4. 也可以在对话中明确让 Bot 新建、读取或更新它的便笺。

例如：“在你的便笺里记下：下次讨论要核对交付日期；先不要执行其他任务。”

保存便笺或标为完成，都不会启动任务、通知其他 Bot 或建立定时执行。需要到时执行的内容应另外创建[定时任务](schedules.md)。

## 草稿和冲突

尚未保存的修改会显示为本机草稿。离开页面后再回来，不应把草稿提示理解为已经保存成功。

若你和 Bot 同时修改，界面会让你比较修改前和最新内容。可保留改过的字段并核对合并，或采用最新版本；保留未改动的新内容后再保存。

结果待确认时，原稿会暂时锁定。先核对回执，重试使用同一份操作，避免重复新建。

## 回收站

把不需要的便笺移入回收站，之后可以恢复。Bot 已归档或环境恢复期间，内容可能只能查看；先处理对应状态再保存。

便笺不是工作偏好，也不是全工作区共享待办。需要影响后续答复方式时用[记忆](memory.md)，需要所有 Bot 共用时用[任务](tasks.md)。
