# 技能说明

[使用文档](README.md) · [English](../en/skills.md)

入口：Bot 工作区的 **技能** 面板。技能保存可复用的工作步骤；它不是应用商店，也不会凭一段说明增加工具权限。

## 新建或导入

1. 点击「新建技能」或「导入技能」。当前导入单份 `SKILL.md`，不支持携带脚本、附件或可执行依赖的完整技能包。
2. 查看名称、用途和正文，确认来源与内容。
3. 保存到共享技能库，再为需要的 Bot 单独启用。
4. 需要手动调用时，点击「加入草稿」，检查指令后发送；加入草稿本身不会执行。

一个最小示例：

```markdown
---
name: weekly-summary
description: 根据已提供的记录生成周报
---

先核对记录的日期范围，再整理已完成事项、问题和下一步。
缺少数据时明确说明，不补造数字。
```

名称使用小写英文短名。技能库由所有 Bot 共用，修改同一技能会影响后续使用它的 Bot；启用状态分别保存，修改从下次任务生效。

## 自动与手动调用

默认可按任务加载，也可通过 `/<技能名>` 手动调用。`disable-model-invocation: true` 可限制自动调用，`user-invocable: false` 可限制手动入口；以面板显示的调用状态为准。

禁用自动调用不等于自动授予手动权限；无论采用哪种方式，都只能使用 Bot 本来有权使用的工具。技能不绕过软件安装、外部调用或电脑授权。

## 编辑、导出和恢复

编辑前先保存或放弃当前草稿。可以导出当前技能说明。移入回收站会关闭所有 Bot 对该技能的启用设置；恢复后需要逐个重新启用。

库中最多保留 100 份技能，含回收站。第三方说明应先审阅，不要把密钥或需要自动运行的安装脚本混进正文。与 Bot 一同分享技能见[导入导出](bot-transfer.md)。
