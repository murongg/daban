# 技能

[使用文档](README.md) · [English](../en/skills.md)

入口：Bot 工作区的 **能力 → 技能**。技能保存可复用的方法，也可以包含脚本、参考资料和模板。技能按 Bot 单独启用，不会凭说明增加工具权限。

## 内置 find-skills

系统自带 Daban 适配版 `find-skills`，默认供各 Bot 使用，可以在技能面板单独关闭。它是只读的系统技能，不需要另装命令行工具。

直接发消息，例如「帮我找一个适合处理 PDF 的技能」。Bot 可以检索 skills.sh、SkillsMP、ClawHub，或预览公开 GitHub 技能目录，说明用途、来源、版本和文件概况。确认安装后，系统把固定版本安装到当前 Bot，并为它启用；本轮即可按需读取新技能继续任务。其他 Bot 的技能列表、版本和启用状态不会改变。

拒绝安装后，同一任务不会继续对相同内容发起安装确认。安装技能不会执行脚本、钩子或依赖安装程序，也不提供平台专有工具。下载限流或网络失败时，可以稍后再试，或者使用本地导入。

## 内置 bot-manager

`bot-manager` 是 Bot 操作的统一技能入口，默认启用，可以为每个 Bot 单独关闭。直接发消息，例如「帮我新建一个负责整理资料的 Bot」，或用 `/bot-manager` 手动调用；Bot 会根据用途拟定名称和职责，保存后可在侧栏打开新搭档。

新 Bot 跟随工作区模型，私人记忆为空，不会复制当前 Bot 的聊天、资料、技能或电脑授权，也不会自动开始任务。同一任务中的相同创建请求只保存一次；修改参数会提示冲突，不会覆盖原 Bot。它创建的是普通 Bot；广场模板的安装和升级使用广场入口。

目前可在对话中直接执行新建；修改资料、复制、归档和恢复会指引到对应管理入口。广场模板的发布、升级和回滚只在运行环境提供相应能力时使用，不会因为启用技能而自动获得这些操作权限。

## 内置 skill-creator

直接说「把这个流程做成一个技能，以后按这个方法做」，或使用 `/skill-creator`。Bot 会整理用途、触发条件和操作方法，生成 `SKILL.md`，必要时附上文本脚本、参考资料或模板。

生成后先预览，确认「安装并启用」才保存到当前 Bot；本轮即可按需读取并继续任务。确认卡展示技能说明、文件数量和摘要，超过展示长度的说明应结合对话中的完整草稿核对。支持文件采用相对路径；二进制资源使用原有技能包导入入口。

生成和安装均不会执行脚本、钩子或依赖安装。同一任务中拒绝后不会为相同内容反复追问；保存不会覆盖已有的不同内容，也不会改变其他 Bot 的技能。修改现有技能仍使用「能力 → 技能」中的编辑或替换技能包入口。

## 本地导入与启用

1. 打开「导入技能」，选择技能文件夹、ZIP 或单份 `SKILL.md`。
2. 查看用途、文件列表和内容，再确认安装。安装只保存文件，不执行脚本或安装依赖。
3. 点击「安装并启用」，只为当前 Bot 安装。新建技能说明的「保存」只保存内容，仍可单独切换启用状态。

安装记录、版本、编辑和卸载按 Bot 独立保存；相同支持文件在底层复用。通过「添加到其他 Bot」明确选择目标，会创建独立副本，以后的修改互不影响。已经运行的任务保留捕获的版本；在对话中明确确认的新安装可供本轮读取，不会顺带加载其他刚启用的技能。系统内置技能不允许编辑、替换或删除。

升级前已有的共享记录会保留并标注。要为当前 Bot 修改它，请先「创建独立副本」。此操作不会修改其他 Bot 使用的旧内容。

## 标准技能包

使用 [Agent Skills](https://agentskills.io/specification) 目录结构，例如：

```text
weekly-summary/
  SKILL.md
  scripts/report.py
  references/guide.md
  assets/template.csv
```

目录直接包含 `SKILL.md`，名称与 frontmatter 的 `name` 一致。可携带其他相对路径的文件，包括二进制模板。每包最多 200 个文件、解包后不超过 5 MiB，ZIP 不超过 6 MiB；不支持符号链接、特殊文件或越界路径。

```markdown
---
name: weekly-summary
description: 根据已提供的记录生成周报
license: MIT
compatibility: Python 3
metadata:
  author: example
---

先读取 references/guide.md。需要计算时准备完整目录，
从该目录运行 scripts/report.py，以便访问 assets/ 中的文件。
缺少记录时明确说明，不补造数字。
```

名称使用小写英文短名。标准包保留许可证、运行要求、元数据和 `allowed-tools` 声明，但这些声明不会自动授予权限。OpenClaw 的命名空间元数据按文件内容保留，不会自动执行其安装步骤或钩子。

## Bot 怎么使用

启用后，Bot 可以按需读取技能说明和资源，也可以准备完整目录后使用其中的脚本。Linux 中执行脚本仍使用现有命令和审批流程；缺少依赖时需要另行安装，安装后结果以执行记录为准。本机 Mac / Windows 模式提供托管资源文件供已授权的图形界面操作使用，不会因此新增宿主机 Shell 权限。

默认可按任务自动调用，也可用 `/<技能名>` 手动调用。`disable-model-invocation: true` 限制自动调用；`user-invocable: false` 限制手动入口，以面板显示为准。

## 编辑、导出与恢复

编辑 `SKILL.md` 会保留支持文件；要更新整个目录，请用「替换技能包」并核对版本。详情里可以预览或下载资源，也可以导出完整 ZIP。单独导出技能说明只包含 Markdown；分享完整技能请使用 ZIP 或[Bot 导出包](bot-transfer.md)。

移入回收站只关闭当前 Bot 的这份安装；恢复后需要重新启用。库中最多保留 100 份技能，含回收站，资源存储上限为 200 MiB。
