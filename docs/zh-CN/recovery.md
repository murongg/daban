# 重新连接与恢复环境

[使用文档](README.md) · [English](../en/recovery.md)

连接中断时，先区分客户端通道、本机电脑授权和 Linux 整个环境。不要直接删除 VM 或用户数据。

## 先尝试重新连接

在 **设置 → 电脑与权限** 使用重新连接或重试连接。它用于重新建立后台连接，不等于要求重启所有应用。Linux 模式下可先做[运行环境检查](diagnostics.md)，定位异常项。

本机 Mac / Windows 控制不可用时，优先检查[本机授权](local-computer.md)、系统权限和暂停状态；不要用 Linux 恢复流程解决主机录屏权限。

## 恢复整个 Linux

1. 打开设置中的「检查并恢复」。
2. 查看所有受影响的 Bot 电脑，而不只看当前 Bot。
3. 先结束正在运行的任务，保存每个应用里未保存的内容。
4. 核对并勾选已保存内容，再明确确认重启整个环境。
5. 等待结果，重新连接需要的 Bot 电脑。

此操作会重启共享 Linux，关闭所有 Bot 的电脑与其中的应用。已保存文件、偏好和聊天保留；应用未保存内容可能丢失，部分网站可能需要重新登录。

## 结果不明时

使用「核对恢复结果」先读取本次状态。关闭弹窗不撤销已提交的重启；重新打开也不会自动反复关机。“取消未执行的恢复”只适用于尚未执行的阶段。

恢复过程中，新任务和电脑操作可能暂缓，草稿仍可编辑，保留的历史与文件可查看。已有计划与排队工作继续受原设置管理，结果不明的操作不会自动重放。

恢复成功后，检查[定时任务](schedules.md)的启用状态与最近触发、浏览器标签和未确认操作。不要用重复执行来替代核对。

恢复运行环境不是从完整备份恢复，更不是恢复被永久删除的原件。
