# 聊天与历史对话

[使用文档](README.md) · [English](../en/conversations.md)

点击侧栏的「新对话」即可开始普通聊天，无需创建 Bot。普通聊天也能使用已授权的工具；问答、写作和内容整理不需要先连接电脑，需要操作图形界面时再连接电脑。

需要长期沿用固定职责、记忆和资料时，选择侧栏中的 Bot。普通聊天的上下文属于该段对话，不会自动带入其他聊天或 Bot 的私人资料。

## 发送任务

1. 说明目标、输入材料和期望产物。
2. 需要时添加[附件](attachments.md)，或给出准确的公开网页链接。
3. 按 Enter 发送，Shift + Enter 换行；输入法正在组词时不会直接发送。
4. 在[执行过程](execution.md)查看计划和工具状态；需要补充或确认时进入[收件箱](inbox.md)。

例如：“对比下面两份方案，列出费用、限制和待核实问题；不要创建文件。”比“帮我看看”更容易得到可检查的结果。

普通聊天默认跟随工作区模型，Bot 会话默认使用 Bot 的模型配置。聊天输入区的模型选择仅用于当前会话的后续消息；Bot 的默认设置在资料编辑中修改。运行中的任务不会因你修改模型而中途切换。生成内容可包含 Markdown、表格、代码和可支持的图表。文件产物可打开预览或到文件面板查看。

## 新对话与旧记录

「最近对话」标题右侧的 **＋ 新增对话** 也可直接开始普通聊天，列表为空时仍可使用。

侧栏「最近对话」统一列出普通聊天和 Bot 会话，Bot 会话附上搭档名称。点击即可切换，打开旧会话不会运行任务或重放工具。标题来自第一条消息，可以通过对话右上方菜单重命名；自定义标题和会话模型选择保存在当前设备。

点击 Bot 对话顶部的「开启新对话」开始独立话题，原会话的草稿、附件和审批选择仍属于原会话。一个 Bot 可以保留多段对话，长期偏好和资料继续归该 Bot 所有；长期要沿用的偏好应保存到[记忆](memory.md)，材料放入[资料](knowledge.md)。

「历史对话」可以读取更早的记录，并通过「继续此对话」回到该段聊天。发送新消息时会显式使用所选会话的上下文；模型或工具权限等发生变化时，系统可能以保留的历史重建兼容上下文，而不是恢复旧授权。文件链接读取的是当前仍保留的文件，不会重建旧文件，也不能证明文件从未被修改。

切换会话或关闭客户端不会停止已经开始的后台任务。同一个 Bot 同时处理一个任务；查看另一段话题时可以先写草稿，任务结束后再发送，也可点击「查看运行中的对话」返回。普通聊天之间使用独立执行身份。排队消息保留在原会话，重新打开客户端后不会自动发送。

普通聊天、统一最近对话和历史续聊需要新版后台运行组件；连接较旧后台时，原有 Bot 聊天和历史查看仍可使用。

## 对话回收站

从最近对话的行菜单或对话右上方菜单选择「移到回收站」。移入后可在提示条中点击「撤销」，也可随时到 **设置 → 对话回收站** 恢复。此处不提供永久删除，也不会定期清空。

移入回收站只收起这段对话，保留消息、未发送草稿、附件和生成文件，不影响 Bot 的记忆与资料。恢复只让它重新出现在列表，不会自动执行旧任务或发送排队消息。所属 Bot 已归档时，先从归档管理恢复 Bot。

运行中或等待确认的任务结束前不能移入回收站，可通过「查看任务」返回。操作结果不明时，请先「核对操作结果」，必要时明确「重试同一操作」；重新打开客户端不会自动重发。整理和恢复需要支持回收站的新版后台，断线时保留本机记录。

## 长对话和草稿

- 上下文接近预算时，系统可能整理较早的上下文；历史记录与模型当前可见的全部原文不是一回事。
- 需要精确引用时，重新提供原文、资料或文件，并要求核对。
- 离开页面时可保留草稿；出现“结果待确认”时，先核对原请求，再决定是否重试。
- 语音输入当前尚未接入；界面语言切换也不会自动翻译你的内容或模型回复。

停止当前工作见[执行过程](execution.md)；整理与搜索见[侧栏整理](organization.md)。
