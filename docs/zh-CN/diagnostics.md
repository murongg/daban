# 运行环境检查

[使用文档](README.md) · [English](../en/diagnostics.md)

入口：Linux 模式下 **设置 → 电脑与权限 → 运行环境 → 检查运行环境**。检查用于定位问题，不会替你重启 Linux 或重跑任务。

## 检查步骤

1. 先确认正在使用完整客户端，而不是网页 UI 预览。
2. 点击检查，等待各项返回。
3. 展开全部检查项，优先处理不可用或需要处理的项目。
4. 修复对应连接或服务后再检查，不要把一次超时当成数据丢失。

## 结果覆盖什么

可检查本地配置、VM、客户端通道、后台服务、DSH 文件、模型配置、Bot 资料、资料库、附件、审批、定时、群聊、技能、外部工具配置、电脑记录和桌面依赖等项目。

| 状态 | 建议 |
| --- | --- |
| 就绪 | 此项检查通过，仍需结合实际任务验证 |
| 需要处理 | 查看受影响的记录或资源，例如待确认的电脑回收 |
| 未配置/未就绪 | 完成对应配置，或先重新连接 |
| 未支持/未检查 | 当前版本没有提供完整结论 |
| 超时 | 连接恢复后重试，不等于内容已删除 |

模型项主要核对保存的配置，不等于真实 API 调用成功。需要测试连通性时，到[模型设置](models.md)测试模型或检查连接。桌面依赖检查也不等于所有图形应用均可正常操作。

## 反馈问题

记录出现问题的步骤、平台、版本、具体检查项和错误；分享截图前遮住密钥、个人内容与敏感网址。当前页面不能替代完整运行日志或完整数据备份。

普通重连、整个环境恢复和重新安装影响不同，先看[故障排查](troubleshooting.md)与[恢复](recovery.md)。

## 按任务需求预检

在单个 Bot 对话的输入区点击 **检查所需能力**，明确选择模型声明、最小输入预算、搜索、Office 解析或电脑访问。只有打开 MCP 选择器时才读取该目标 Host 中此 Bot 已授权并选定的精确工具；目录来自缓存，不会连接外部 MCP 服务。普通发送无需先完成预检。

检查逐项显示就绪、缺少条件、未知、已变化或未支持，并注明事实来源与采样时间。模型配置已保存不表示推理调用成功；输入预算仅比较配置的上下文窗口减去最大输出，不估算本次完整输入。预检不申请权限、接管电脑、启动 VM、登录账号或修复环境；发送任务仍执行原有授权检查。

报告超过 30 秒会标为可能变化，5 分钟后需重新检查。修改需求、模型、附件类型或切换 Bot/Host 会作废当前视图；取消等待和关闭面板都不会停止后台任务。

点击 **预览诊断包** 可阅读将要下载的确切白名单 JSON。只有点击 **下载此诊断包** 才进行本地下载，且下载内容必须与预览一致。包内使用 Bot、连接和工具别名，不含聊天正文、文件、账号、地址或原始错误；界面不提供发送或上传。Host 重启后不恢复旧报告。旧服务未声明预检能力时保留原有环境检查。
