# 设置与界面偏好

[使用文档](README.md) · [English](../en/settings.md)

入口：侧栏底部设置按钮，或 Cmd + , / Ctrl + ,。设置以独立弹框显示，左侧选择分类，右侧编辑对应选项。

## 分类导航

| 分类 | 内容 |
| --- | --- |
| 通用 | 浅色/深色、界面语言、桌面提醒 |
| 模型与供应商 | 模型连接、列表、测试、能力匹配、默认模型 |
| 电脑与权限 | 本地连接状态、系统权限、Linux 检查与恢复 |
| 外部工具 | MCP 连接及各 Bot 的工具选择 |
| 归档管理 | 查看和恢复 Bot、群聊 |
| 对话回收站 | 恢复收起的对话，保留消息、草稿和文件 |
| 数据与存储 | 客户端数据说明与工作区导出 |
| 关于 | 当前版本与能力范围 |

分类内可能因平台或后台版本隐藏不适用的项目。Windows 本机模式不会出现完整 Linux 检查和重启流程。

## 主题与语言

在通用页面选择浅色或深色。界面语言可在简体中文与 English 间即时切换，并保存在这台设备。

切换语言只翻译应用文案，不翻译你命名的 Bot、资料、输入内容或模型回答。希望 Bot 使用另一种语言时，在聊天或[工作记忆](memory.md)中明确说明。

## 保存与关闭

主题等选项可即时生效，模型与外部连接表单则需点击对应保存。看到编辑内容不代表已经保存；按各表单的提示核对。

未提交的 Key 不会作为已保存配置保留。关闭设置、重启或刷新客户端前，先处理需要保存的表单。提交后结果待确认的操作，应通过原请求核对，而不是重新填写另一份。

模型、工具、系统权限和控制权各有独立范围，详见[模型](models.md)、[外部工具](integrations.md)与[本机桌面](local-computer.md)。当前仍为早期预览，公开分发签名、公证和完整自动更新流程尚待完善。
