# 桌面提醒

[使用文档](README.md) · [English](../en/notifications.md)

入口：**设置 → 通用 → 桌面提醒**。桌面提醒用于后台任务完成、失败或等待你处理时提供入口，不会展示完整任务正文。

## 开启和测试

1. 打开「接收桌面提醒」。
2. 核对系统通知设置，确保 Daban 可以显示通知。
3. 点击「发送测试提醒」。测试不会启动 Bot 任务或提交审批。
4. 按需设置每位 Bot 的私聊提醒开关。

总开关关闭时不弹出提醒，但各 Bot 的选择会保留。关闭某位 Bot 的私聊提醒，不影响群聊提醒或收件箱中的待处理内容。

## 收到提醒后

点击提醒可尝试进入对应请求或任务结果。若链接无法打开，在[收件箱](inbox.md)、当前会话或历史对话中核对，不要仅凭通知文字确认任务已成功。

提醒只说明类型；不展示任务、问题的完整正文或把通知中心当作完整记录。

## 没有弹出怎么办

- 系统的勿扰、专注模式、通知权限和显示设置可能影响展示。
- 在完整桌面客户端测试；网页预览不会请求系统通知权限。
- 后台或版本不支持时，以收件箱和会话记录为准。
- 完整退出客户端后，不会继续发现新提醒；Linux 中的后台任务仍可能继续执行。重新打开可查看结果。

通知开关只保存在这台电脑，不是手机推送或跨设备提醒服务。
