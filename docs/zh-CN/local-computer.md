# 本机 Mac / Windows 桌面

[使用文档](README.md) · [English](../en/local-computer.md)

本机模式让 Bot 操作你正在使用的真实电脑，范围是主显示器及当前用户可操作的应用。它与隔离的 Linux 桌面不同。

## 授权连接

1. 为 Bot 选择支持图片的模型，等待当前任务结束。
2. 打开「电脑」面板，选择「本机 Mac」或「本机 Windows」。
3. macOS 按「系统权限」入口完成屏幕录制和辅助功能授权。系统权限与 Bot 的临时控制授权是两回事。
4. 点击连接，核对弹窗中的 Bot、模型和供应商。授权表示允许观察主显示器并向该模型服务发送屏幕图像，以及执行键鼠操作。
5. 明确告诉 Bot 要处理哪个应用、什么任务，保持电脑解锁和唤醒。

开始前关闭或移走不希望出现在模型截图中的窗口。Daban 不会因为选择本机模式，就自动获得管理员权限。

## 暂停、恢复和断开

- 回到 Daban 或点击暂停，可将输入控制留给你。
- 紧急暂停：Mac 使用 **Ctrl + Option + Esc**，Windows 使用 **Ctrl + Alt + Esc**。
- 在面板中核对状态后，主动恢复或交还给 Bot。焦点变化、锁屏、休眠和过期观察也可能暂停动作。
- 断开连接或完整退出客户端后，原会话授权失效。下次连接需重新确认；更换模型或连接也可能要求重新授权。

同一时刻只允许一位 Bot 使用本机桌面。切换使用者时先断开原会话，再为另一位 Bot 授权。其他 Bot 不能各自获得一个独立的 Mac 或 Windows 屏幕。

## 能力边界

Bot 可以截图、点击、键入、滚动，使用 Dock、开始菜单及真实应用。这里不提供绕过 GUI 的宿主机 shell 或任意文件工具；也不能假定能控制管理员窗口、UAC、安全桌面或副显示器。

本机 GUI 操作作用于真实文件和已登录账号。不要把 VM 内的命令审批机制误认为每次本机点击前都会弹出审批。高影响操作应在任务中明确边界，必要时由你接管完成。

权限显示已开启但仍不可用时，见[故障排查](troubleshooting.md)。
