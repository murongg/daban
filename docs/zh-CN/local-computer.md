# 本机 Mac / Windows 桌面

[使用文档](README.md) · [English](../en/local-computer.md)

在对话里直接告诉 Bot 要操作哪个本机 App、做什么，并为 Bot 选择支持图片的模型。Bot 会在对话中申请权限，同意后继续原任务。当前任务使用「完全访问权限」时，Daban 会跳过这次确认。

macOS 首次使用前，要在系统设置里为 Daban 开启「辅助功能」和「屏幕录制」权限。「电脑」面板的本机标签页会引导设置。如果 macOS 提示重启 Daban，请按提示操作。系统权限在所有审批模式下都需要。

Bot 也可以在对话中按需申请使用内置浏览器或已安装的 Linux 桌面，不用先在电脑面板连接。「完全访问权限」也适用于这两种申请。

## 后台操作

Daban 使用内置的 Cua Driver，截取并操作已授权 App 的一个窗口，不会接管系统鼠标。支持的 Mac App 可以在后台启动。Windows 上，请先打开目标 App，再让 Bot 操作。

Bot 可以点击受支持的控件，并在 macOS 上向受支持的输入框输入文字。窗口可以被其他 App 遮挡，但不能最小化、隐藏或关闭。部分控件以及滚动、拖拽、快捷键无法在后台操作。后台动作失败时，Daban 不会切换到前台操作。

后台点击时会短暂显示彩色 Bot 指针。在同一显示器的同一窗口内连续点击时，指针会从上一次点击处滑到新位置。

## 暂停和断开

- 任务使用本机窗口时，可以在本机标签页暂停、恢复或断开。
- 紧急暂停：Mac 按 **Ctrl + Option + Esc**，Windows 按 **Ctrl + Alt + Esc**。
- 同一时间只允许一位 Bot 操作本机窗口。任务结束或你手动断开后，本机窗口授权失效。

系统权限显示已开启但仍不可用时，见[故障排查](troubleshooting.md)。
