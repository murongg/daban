# 本机 Mac / Windows 桌面

[使用文档](README.md) · [English](../en/local-computer.md)

本机模式让 Bot 操作你正在使用的真实电脑。macOS 和 Windows 都可以选择一个已打开的窗口进行后台控制，也可以选择前台控制主显示器。

## 授权连接

1. 为 Bot 选择支持图片的模型，等待当前任务结束。
2. 打开「电脑」面板，选择「本机 Mac」或「本机 Windows」。
3. macOS 面板会显示两步权限引导：先点击「开启辅助功能」，再点击「开启屏幕录制」，按系统提示为当前 Daban 打开对应开关。返回 Daban 后自动检测，也可点击「重新检查权限」。若 macOS 要求退出并重新打开，请按提示重开应用。系统权限与 Bot 的临时控制授权是两回事。
4. 点击连接，选择要后台操作的窗口，或选择「整个主显示器（前台）」。核对 Bot、模型和供应商，再授权操作和发送所选范围内的截图。
5. 明确告诉 Bot 要处理哪个应用、什么任务，保持电脑解锁和唤醒。

开始前关闭或移走不希望出现在模型截图中的窗口。Daban 不会因为选择本机模式，就自动获得管理员权限。

## 暂停、恢复和断开

- 点击「暂停操作」即可暂停。前台模式下，回到 Daban 也会暂停。
- 紧急暂停：Mac 使用 **Ctrl + Option + Esc**，Windows 使用 **Ctrl + Alt + Esc**。
- 在面板中核对状态后，主动恢复或交还给 Bot。焦点变化、锁屏、休眠和过期观察也可能暂停动作。
- 断开连接或完整退出客户端后，原会话授权失效。下次连接需重新确认；更换模型或连接也可能要求重新授权。

同一时刻只允许一位 Bot 使用本机桌面。切换使用者时先断开原会话，再为另一位 Bot 授权。其他 Bot 不能各自获得一个独立的 Mac 或 Windows 屏幕。

## 能力边界

后台模式通过内置的 Cua Driver SDK 截取授权窗口，并通过 macOS 辅助功能或 Windows UI Automation 点击支持的控件。macOS 还可以在支持的可编辑字段中插入文字。Windows 需要切换到前台模式才能输入文字。窗口被其他应用遮挡时仍可操作，最小化、隐藏或关闭后将不可用。操作另一窗口需要重新授权。滚动、拖拽、快捷键和自绘控件需要前台模式。

后台点击时，目标窗口上会短暂显示彩色 Bot 指针，遮挡目标的窗口也会挡住指针。系统鼠标仍由你控制，暂停或断开时会清除 Bot 指针。

前台模式下，Bot 可以截图、点击、键入、滚动，使用 Dock、开始菜单及真实应用。这里不提供绕过 GUI 的宿主机 shell 或任意文件工具；也不能假定能控制管理员窗口、UAC、安全桌面或副显示器。

本机 GUI 操作作用于真实文件和已登录账号。不要把 VM 内的命令审批机制误认为每次本机点击前都会弹出审批。高影响操作应在任务中明确边界，必要时由你接管完成。

权限显示已开启但仍不可用时，见[故障排查](troubleshooting.md)。
