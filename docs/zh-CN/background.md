# 后台运行与长进程

[使用文档](README.md) · [English](../en/background.md)

Daban 的本地后台与客户端窗口分别运行。窗口关闭后，一些任务仍可继续；这不代表它们运行在云端。

## 什么可以继续

Linux 中已经启动的任务和长命令可能继续使用原环境。定时任务由本地后台管理，执行条件见[定时任务](schedules.md)。

要持续运行，电脑仍需开机、唤醒，后台和相关网络保持可用。笔记本合盖、系统休眠、关机和断网都可能影响执行。本机桌面控制则依赖客户端及临时授权，退出后不能当作仍有操作权限。

## 安装、构建或脚本运行较久时

1. 说明需要执行的任务和预期产物，让 Bot 使用适合长时间工作的进程工具。
2. 保留原进程标识，查询状态、日志和退出结果，而不是再次启动同一命令。
3. 完成后检查退出状态及实际文件或版本。
4. 需要停止时，要求停止那个具体进程或当前任务，并核对结果。

例如：“构建可能较久，请启动后检查同一个进程，完成后验证产物，不要重复启动。”这些程序化进程工具属于 Linux 能力，Windows 本机模式不提供同等工具。

## 切换页面与结束工作

切换 Bot、关闭面板或收起窗口，不等于停止模型任务。停止任务也不一定撤销已经启动的系统进程或已发生的外部操作，应检查当前状态。

同一位 Bot 忙碌时，先等待、停止或处理它当前的请求，不要假定任意追加消息都进入通用后台队列。群聊和定时任务各有自己的排队状态。

退出后不会发现新的客户端桌面提醒；重新打开会话、[收件箱](inbox.md)或相关进程记录核对结果。出现中断或未知结果时，先观察再决定是否重试。
