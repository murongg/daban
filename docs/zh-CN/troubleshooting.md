# 常见问题与排查顺序

[使用文档](README.md) · [English](../en/troubleshooting.md)

先保留已有聊天、文件和配置，再定位具体问题。界面显示为空、超时或结果待确认，都不等于后台记录已经删除。

## 无法开始聊天

1. 确认使用完整客户端，不是网页 UI 预览。
2. 完成[模型引导](models.md)，检查 Key、API 地址、协议和模型 ID。
3. 测试真实模型调用。列表读取成功不等于调用可用；余额、限流、模型权限和网络都可能造成失败。
4. 当前任务仍在运行或等待确认时，先处理它。

## 搜索要求 Key 或暂时不可用

在「设置 → 搜索」检查当前供应商。DuckDuckGo 无需 Key；DeepSeek 和 Brave 需要对应的搜索凭据，聊天模型 Key 不会自动替代它。新用户默认使用 DuckDuckGo，已有配置会保留。DuckDuckGo 遇到验证码、限流或页面变化时会报错，不会自动改用其他供应商。旧 Host 若仍提示只支持 DeepSeek，请更新客户端与 Host。已有公开网址可直接请求读取，见[网页调研](web.md)。

## 网页只有标题、提示截断或没有正文

要求重新读取本次实际结果。普通文章现在先提取正文再分页；长文应续读同一快照。超出下载上限、登录、验证码、反爬或 JavaScript 页面不能保证匿名读取，必要时改用浏览器或提供原文。HTTP 200 不保证是目标正文。

## 图片、PDF 或 Office 无法使用

图片检查模型的图片能力。PDF/Office 需要 Linux 文档解析；扫描件需 OCR，加密文件需解密。检查格式、大小、最多 4 个附件的限制，等待上传结束后再发送，见[附件](attachments.md)。

## 电脑无法连接或不能点击

先确认选择了 Linux 还是本机模式。Linux 检查运行环境、空闲名额、待回收资源及当前任务；只读画面需要先接管。

本机检查是否已选择图片模型、系统录屏/输入权限、临时授权、主显示器、解锁和暂停状态。Mac 更换临时签名的开发包后，旧权限条目可能失效；在系统设置中核对当前应用条目，按系统要求重新授权并重开应用，不要关闭系统保护来修复。

## 保存或外部操作结果待确认

使用原请求的核对入口，先查看回执与实际状态。不要重复创建 Bot、再次安装或重新提交网站表单。关闭弹窗并不撤销已经提交的请求。

## 定时任务没运行、通知没收到

检查启用开关、时间与时区、Bot 是否可用、电脑是否开机唤醒、后台及网络状态；查看最近触发。锁定不是暂停，错过的次数也不一定逐次补跑。

通知另受系统权限和勿扰模式影响；完整退出客户端后不再发现新提醒。到会话和收件箱核对结果。

## 文件缺失或磁盘空间占用大

旧文件链接不是不可变备份。检查文件面板、附件管理、资料原件与各自回收站。VM、原件和安装缓存均可能占空间；清理附件时保留内容与配额变化不一定让数据库立即缩小。

不要误删现用 VM、浏览器配置、用户目录或唯一备份。[工作区导出](workspace-export.md)不包含这些完整内容。

## 进一步定位

Linux 模式先运行[环境检查](diagnostics.md)，再考虑[整体恢复](recovery.md)。记录平台、版本、步骤和具体错误反馈给维护者，不发送 API Key、完整敏感导出或未遮挡的私人屏幕。

## 从早期开发版升级后无法连接

新版会先连接兼容的旧工作区，并提示升级后台。请结束当前任务、处理或取消排队的群聊任务、暂停定时任务，再确认「重启并升级后台」。这会重启 Daban 的 Agent 服务，Linux 电脑保持运行，聊天、文件和登录状态保留。也可以选择「稍后」继续使用旧工作区，之后从运行环境设置进入后台升级。仅关闭客户端窗口不会退出后台服务。
