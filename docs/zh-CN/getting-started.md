# 开始使用

[使用文档](README.md) · [English](../en/getting-started.md)

Daban 是运行在本机的 AI 工作区。先配置模型，再创建 Bot；普通对话不需要连接电脑。

## 准备什么

| 运行方式 | 当前支持 | 用途 |
| --- | --- | --- |
| Apple 芯片 Mac + Linux 虚拟机 | 独立 Linux 桌面、浏览器、文件与命令工具 | 多 Bot 分别操作，共享文件和登录 |
| macOS 本机桌面（当前 Mac 包为 Apple 芯片版本） | 当前用户的主显示器 | 使用 Mac 上的真实应用 |
| Windows x64 本机桌面 | 当前用户的主显示器 | 使用 Windows 上的真实应用 |

准备维护者提供的完整客户端，以及一家模型供应商的 API Key。模型费用由供应商账户承担。客户端首次使用时下载并缓存后台和 DSH，无需另装 Docker、Node.js 或 DSH；仅克隆源码不等于获得完整客户端。

## 第一次打开

1. Mac 用户将应用放在固定位置再打开；Windows 用户解压完整便携包，运行其中的 `Daban.exe`，不要只复制可执行文件。
2. 选择简体中文或 English。
3. 按引导下载并缓存基础运行组件，可暂停和继续。不需要先创建虚拟机；Linux 电脑可以以后按需安装。
4. 在模型引导中选择供应商，填写 API Key，选择或填写模型。验证保存后点击「开始使用」。详细步骤见[模型与供应商](models.md)。
5. 从[Bot 广场](gallery.md)添加搭档，或[创建自己的 Bot](bots.md)。新工作区默认没有示例聊天或测试 Bot。
6. 发出第一个任务，例如：“把下面的会议记录整理成结论和待办。”

## 需要电脑时再连接

打开 Bot 的「电脑」面板，选择 [Linux 虚拟机](linux-computer.md)或[本机桌面](local-computer.md)。电脑操作需要相应能力与授权；聊天、写作和部分工作区工具不要求连接图形桌面。

## 日常使用

- 等待确认或补充问题时，打开[收件箱](inbox.md)。
- 偏好写入[记忆](memory.md)，长期参考材料放入[资料](knowledge.md)。
- 关闭窗口、退出客户端、电脑休眠是不同情况：本地后台任务可能继续，但本机桌面授权会在退出客户端时撤销；休眠、关机或断网会影响执行。
- 当前不提供托管云端电脑、手机客户端或跨设备同步。运行任务的电脑需要保持可用。

遇到问题先看[故障排查](troubleshooting.md)，保留现有数据，不要把删除 VM 或用户目录作为第一步。

## 按需安装 Linux 电脑

首次打开客户端会下载并缓存后台、Node.js 和 DSH，配置模型后即可聊天，不需要先安装虚拟机。需要独立 Linux 屏幕、终端和工作文件时，再从电脑面板或运行环境设置安装。Lima 工具、Linux 执行程序和系统镜像仅在你选择安装后下载，可以暂停和继续；下载缓存和已有环境会复用。建议为首次安装预留 40 GB 可用磁盘空间。目前 Linux 模式支持 Apple 芯片 Mac，Windows 使用本机桌面模式。
