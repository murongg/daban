# 浏览器、登录与网页交互

[使用文档](README.md) · [English](../en/browser.md)

浏览器面板用于实际网页交互。独立浏览器无需安装 Linux，也无需开启本机屏幕录制或辅助功能；文本模型可使用页面结构工具。仅阅读公开文章时，优先使用[网页读取](web.md)。

## 独立浏览器

1. 点击对话顶部的「浏览器」，或从电脑面板选择「浏览器」。
2. 查看账号与页面内容的使用说明，点击「打开浏览器」。后台会使用 Chrome、Edge 或已安装的 Chromium，为 Daban 创建专属配置；不会读取个人浏览器配置。
3. 初次打开由你控制。输入网址，在面板中完成登录或验证码。
4. 点击「交还给 Bot」，再交代网页任务。Bot 使用当前登录状态读取页面、点击和填表。

每位 Bot 管理自己的标签，同一个 Daban 工作区共用独立浏览器的登录。关闭面板不会断开，断开会关闭这位 Bot 的标签并保留浏览器配置。重启后台后需重新打开并交还；原有网址保持「等待恢复」，不会自动重新访问。网站仍可能让登录过期。

独立浏览器、Linux 浏览器和个人 Chrome 的登录分别保存。切换到本机桌面或 Linux 前，先结束当前任务并断开这位 Bot 的独立浏览器。运行中的任务不会因浏览器断开而改用另一种操作环境。

独立浏览器当前提供网页读取和操作，未提供模型文件上传、下载工具或宿主机文件访问；网页文件选择可由你接管处理。需要工作区文件传输时使用 Linux 浏览器。网页访问保留私有网络和本机服务地址限制。

## Linux 浏览器的打开和接管

1. 为 Bot 连接 [Linux 电脑](linux-computer.md)。
2. 在电脑面板切换到「浏览器」，查看当前标签。
3. 点击「接管电脑」后，可输入网址、前进、后退、刷新、新建和关闭标签，并操作网页。
4. 完成后交还给 Bot，让它继续工作。

Bot 可以按任务使用页面结构和浏览器工具，也可观察桌面；并不是所有网页步骤都必须通过截图和坐标点击。

## 登录状态如何共享

需要登录时，可以先接管完成登录，再交还。Bot 的页面与标签分别管理，但浏览器登录状态在共享环境中共用。在一个页面退出账号或修改登录状态，可能影响其他 Bot。

该登录不等于宿主机 Safari、Chrome 或 Edge 的个人资料，也不会自动迁移到另一台设备。与本机真实浏览器交互，应使用[本机桌面模式](local-computer.md)。

## 弹窗、上传和下载

留意网页对话框、新窗口、文件选择和下载请求。上传会把选定文件发送给目标网站，下载结果应在[文件面板](files.md)核对实际内容。登录、验证码或付款等需要人工处理的步骤，可以接管完成后继续。

出现“操作结果未确认”时，先使用核对入口或观察网页当前状态。提交、付款、上传等操作不能仅因没看到回执就再次点击。

## 恢复后的页面

重启或恢复后，旧标签可能显示「等待恢复」，不会自动重新访问全部历史网址。需要时选择重新打开页面。曾经的登录状态不能保证任何网站永远保持登录。

不要在共享浏览器中混用需要严格隔离的身份。文件和登录的共享边界见[隐私与权限](privacy.md)。
