# Bot 导入与导出

[使用文档](README.md) · [English](../en/bot-transfer.md)

用于分享或迁移选定的 Bot 内容，不是完整工作区或登录环境备份。只需在本工作区复制职责时，可用[复制 Bot](copy-bot.md)。

## 导出

1. 打开 Bot 资料，选择「导出 Bot」。
2. 核对已保存的职责，选择要包含的工作偏好、技能说明和当前资料。
3. 按需勾选资料原件，特别是 PDF/Office 原件。
4. 点击「下载导出包」，保存 JSON 文件。

导出只包含选中的已保存内容，不包含未保存草稿或资料的全部历史版本。原件可能比当前正文包含更多内容，分享前应检查。

## 导入

1. 打开新建 Bot 的入口，选择「导入 Bot」。
2. 选择 Daban 导出的 UTF-8 JSON，最大 100 MiB。
3. 查看职责、偏好、技能和资料预览，确认来源。
4. 选择「导入为新 Bot」，等待导入完成。
5. 核对新 Bot 的模型选择和资料，按需手动启用导入的技能。

含 PDF/Office 原件的导入需要可用 Linux 文档解析能力。导入不会自动运行任务或连接电脑，技能说明默认不会自动启用。

## 不迁移的内容

聊天记录、模型连接和 API Key、外部工具授权、电脑授权、浏览器登录不会随导出包迁移。导入创建独立身份，不会覆盖一位现有 Bot。任务、日程、便笺等没有明确列在预览中的内容也不能假定已迁移。

## 中断与核对

关闭弹窗不取消已经提交的导入。结果待确认时，使用保留的进度入口；需要重新选择文件时选择同一份内容，不要反复提交不同副本。先核对已创建的 Bot，再决定是否开始另一轮导入。

导出包可能包含业务资料与偏好，请按实际内容决定分享范围。它不能替代[工作区数据保留](workspace-export.md)。
