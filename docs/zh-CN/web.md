# 网页调研与正文读取

[使用文档](README.md) · [English](../en/web.md)

公开网页调研通常不需要连接电脑。搜索、匿名正文读取和登录后的浏览器操作是三种不同能力。

## 搜索与指定链接

- 要找资料，可以说：“搜索这个主题，列出原始来源，再比较观点。”搜索供应商与聊天模型分别配置；没有搜索配置的新用户默认使用免 Key 的 Bing；旧版自动创建、从未保存且无凭据的空 DeepSeek 默认配置也会升级。已有的供应商（包括 DuckDuckGo）、关闭状态和旧 DeepSeek 引用设置会保留。
- 已有网址时，直接粘贴完整的公开 HTTP(S) 链接，让 Bot 读取并附来源。匿名网页读取本身不需要搜索 API Key。
- 在「帮我批准」模式下，Bot 可直接读取你在当前任务里给出的链接、本次搜索返回的链接，以及这些页面正文中实际出现、符合条件的同站链接。链接跟进仅限当前任务。跨站、带查询参数或明显涉及账户和操作的后续链接需要单次确认；自动跟进的链接遇到重定向会停下。

## 配置搜索

使用包含独立搜索功能的客户端和 Host，在「设置 → 搜索」选择供应商并保存：

- **Bing（免 Key）**：无需填写凭据，使用必应公开搜索结果页。
- **DuckDuckGo（免 Key）**：无需填写凭据，使用 DuckDuckGo 公开搜索结果页。
- **DeepSeek**：填写 DeepSeek 官方开放平台 API Key，也可继续使用已保存的旧官方连接引用。
- **Brave**：填写 Brave Search API Key。

保存和刷新状态不会发起搜索。「测试搜索」需要明确确认，向选定供应商发送一次固定查询；DeepSeek/Brave 可能收取搜索费用。完成配置后发起新任务，正在运行的任务保持原搜索快照。请求失败不会自动切换供应商或重试。

免 Key 搜索仍需联网，网络限制、限流、验证码或页面改版都可能导致暂时不可用，不能保证所有国内网络都能直连。遇到验证提示时，可主动切换供应商。设置页状态来自最近一次搜索或测试；实际任务失败会更新诊断，较早的任务或测试结果不会覆盖较新的结果。

搜索优先使用 Host 已保存的 `network.json` 代理配置（`null` 表示明确关闭）。没有该配置时，依次读取 `DSH_NETWORK_PROXY`、`https_proxy`/`HTTPS_PROXY`、`all_proxy`/`ALL_PROXY`，并遵循 `no_proxy`/`NO_PROXY`。支持 HTTP(S) 代理；配置无效时会报错，不会改为直连重试。环境变量应配置在 Host 进程，Host 可能与桌面客户端分开运行。此功能不修改系统代理，也不自动读取 PAC 设置。DNS 返回代理映射地址时，公共 DNS 解析也通过配置的代理进行；目标公网 IP 校验和 TLS 证书验证仍然生效。

## 正文如何读取

工具先在下载上限内读取 HTML，再清理脚本、隐藏内容和导航，提取正文。普通文章通常一次返回；长文通过同一份临时快照继续读取，不会每翻一段就重新下载不同版本。

默认每次返回约 16,000 个文本位置，单页最多 32,000；原始响应上限为 2 MiB。快照有保留时间和容量限制，重启或过期后需从头重新读取。Bot 会收到续读位置，你不需要自己操作分页。

可以这样要求：“读取这三个链接的正文，若有续页请读到末尾；区分文章原话、你的归纳和无法核实的内容。”

## 读取失败怎么办

1. 让 Bot 报告本次实际返回的 HTTP 状态或错误，不要沿用上一次的结论。
2. 下载超限、正文为空或 HTML 无法安全处理时，不能把标题当作完整正文总结。
3. 登录页面、验证码、反爬提示、主要依赖 JavaScript 的页面，可能需要[浏览器](browser.md)；匿名读取不会使用已有浏览器登录。
4. 必要时提供可读取的文本、导出文件或截图。HTTP 200 只代表收到页面，不证明取得了目标正文或核实了报道内容。

网页文字是参考材料，不会授予新的权限。涉及外部操作时仍需按[审批](approvals.md)处理。
