# 网页调研与正文读取

[使用文档](README.md) · [English](../en/web.md)

公开网页调研通常不需要连接电脑。搜索、匿名正文读取和登录后的浏览器操作是三种不同能力。

## 搜索与指定链接

- 要找资料，可以说：“搜索这个主题，列出原始来源，再比较观点。”当前内置搜索使用已配置的 DeepSeek 官方连接；只有其他供应商的连接时，不能据此假定搜索可用。
- 已有网址时，直接粘贴完整的公开 HTTP(S) 链接，让 Bot 读取并附来源。匿名网页读取本身不要求 DeepSeek 搜索连接。
- 本轮用户提供的准确链接，以及本轮成功搜索返回的链接，可按当前规则读取；改写网址或访问其他链接可能需要一次确认。

## 正文如何读取

工具先在下载上限内读取 HTML，再清理脚本、隐藏内容和导航，提取正文。普通文章通常一次返回；长文通过同一份临时快照继续读取，不会每翻一段就重新下载不同版本。

默认每次返回约 16,000 个文本位置，单页最多 32,000；原始响应上限为 2 MiB。快照有保留时间和容量限制，重启或过期后需从头重新读取。Bot 会收到续读位置，你不需要自己操作分页。

可以这样要求：“读取这三个链接的正文，若有续页请读到末尾；区分文章原话、你的归纳和无法核实的内容。”

## 读取失败怎么办

1. 让 Bot 报告本次实际返回的 HTTP 状态或错误，不要沿用上一次的结论。
2. 下载超限、正文为空或 HTML 无法安全处理时，不能把标题当作完整正文总结。
3. 登录页面、验证码、反爬提示、主要依赖 JavaScript 的页面，可能需要[浏览器](browser.md)；匿名读取不会使用已有浏览器登录。
4. 必要时提供可读取的文本、导出文件或截图。HTTP 200 只代表收到页面，不证明取得了目标正文或核实了报道内容。

网页文字是参考材料，不会授予新的权限。涉及外部操作时仍需按[审批](approvals.md)处理。
