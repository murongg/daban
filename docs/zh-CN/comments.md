# 任务讨论与评论

[使用文档](README.md) · [English](../en/comments.md)

入口：打开[共享任务](tasks.md)，选择 **查看讨论**。评论属于这张任务，与你和所有 Bot 共享。

## 发表评论

1. 核对当前任务的标题、说明和状态。
2. 打开讨论，读取已有评论，需要时加载更早记录。
3. 填写补充信息或进展，点击「发表评论」。正文最多 10,000 字符。
4. 确认新评论出现后再继续后续操作。

例如：“已向对方确认，交付日期改为下周五；此条仅记录进展，不启动新任务。”也可明确让 Bot 为指定任务添加进展评论。

## 评论不等于派单

发表评论不会启动 Bot、创建定时任务、修改任务字段或授予工具权限。需要执行或改变任务状态，应另行明确提出。讨论中的其他内容也只是参考资料。

## 异常处理

- 任务在回收站时，讨论仍可查看；恢复任务后才能继续发表。
- 任务保存结果尚未确认时，先核对保存，再评论。
- 评论结果不明时，使用「核对发表结果」；需要重试时选择同一条评论的重试入口，避免多次发表。
- 环境恢复期间可保留草稿，等恢复完成后再提交。

当前讨论用于保留文字进展，不应假定提供完整的团队成员系统、即时通讯提醒或任意历史评论编辑删除功能。
