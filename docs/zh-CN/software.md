# 在 Linux 中安装软件

[使用文档](README.md) · [English](../en/software.md)

适用：Linux 虚拟机模式。安装到共享 Linux 系统的软件可以供其他 Bot 使用；这不是向你的 Mac 或 Windows 主机安装软件。

## 让 Bot 安装

1. 说明软件、用途和安装范围，例如：“在共享 Linux 环境中安装这个命令行工具，先列出要执行的安装操作。”
2. Bot 可以使用软件安装流程或 VM 命令/进程工具。需要确认时，会出现软件计划或命令审批。
3. 核对来源、包名或命令、版本、依赖、安装位置及影响范围，再允许这一次操作。
4. 在执行记录里等待实际安装结果。审批成功只代表允许执行，不代表软件已经安装成功。
5. 让 Bot 验证命令版本，或实际启动应用。必要时换一位 Bot，验证它也能使用共享安装。

## npm、Codex 和其他工具

VM 内可以安装 Node/npm 生态工具及 Codex 等 CLI，仍需满足网络、架构、许可证和工具自身要求。软件的账号登录与模型 API Key 配置是独立步骤，安装不等于已登录。

需要所有 Bot 使用时，明确要求安装在共享位置并检查命令搜索路径；某个项目目录下的局部 npm 依赖不等于系统全局命令。

## 安装较慢或结果不明

长任务可能在后台进程中继续。让 Bot 查询原进程和安装记录，不要因界面暂时没有输出而重新执行安装。失败时先查看错误，例如网络、仓库、依赖或权限问题，再决定修复步骤。

Bot 在 VM 内具有完整系统权限，包括 sudo，但[审批](approvals.md)仍管理高风险操作。升级、卸载、改系统设置也可能影响其他 Bot；独立桌面不会隔离这些影响。

在本机模式下安装真实 Mac/Windows 软件属于主机操作，不能套用这里的 Linux 隔离与共享说明。
