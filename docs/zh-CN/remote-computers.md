# 局域网电脑接入

首版支持同一局域网中的电脑。两端安装同版本 Daban，受控端保持开机、登录桌面并运行 Daban。连接服务内置于客户端，无须搭建服务器、SSH 转发或配置 TURN。

## 第一次连接

1. 在受控电脑打开「远程电脑 → 允许连接本机」，点击「开启并复制连接链接」。
2. 在控制端打开「远程电脑 → 连接另一台电脑」，粘贴链接并点击「连接」。首次引导页也有这个入口，控制端不必先配置本机模型。
3. 受控端会显示请求设备名称。确认是自己的设备后，点击「允许连接」。批准后，控制端自动打开那台电脑的工作区。

连接链接五分钟内有效，只供本次新设备配对使用。链接包含公开身份和证书，以及高熵的一次性配对秘密；请直接发送到自己的另一台设备。设备私钥留在本机。

系统可能要求允许 Daban 使用专用网络或访问局域网。双方需要能互相访问，访客 Wi-Fi 或网络隔离可能阻止连接。

## 之后使用

已配对电脑保留在设备列表中，点击「打开工作区」即可。临时断网后，当前选中的工作区会自动尝试重新连接。受控端的模型配置、文件、审批和任务归该电脑所有，控制端断开不会取消已接收的任务。

在远端工作区配置模型、创建 Bot，再连接对应的原生桌面。Bot 需要支持图片输入的模型，受控端另行批准桌面访问。macOS 屏幕录制与辅助功能权限仍由系统在受控端授予。

人工接管继续校验设备、Bot、会话 revision 和新鲜观察；断线会释放该连接持有的键鼠，并保持人工暂停，不自动交还 Bot。普通 Escape 把键盘焦点移回文字框，Alt+Escape 可发送远端 Escape。

原生实时视频使用独立 WebRTC 连接。工作区操作使用证书固定的 TLS WebSocket，不依赖 ICE 或视频建立成功；视频不可用时仍可在授权接管后使用截图操作。既有 Linux VM 保持自己的执行器与截图预览，本次不增加 VM 视频。

## 管理授权

「设备与授权」中可查看完整指纹、只读接入地址及配对设备。

- 在控制端移除电脑，删除的是本机的连接记录。
- 在受控端撤销设备授权，会断开其当前连接、释放输入并拒绝之后的访问。
- 「停止接入」关闭局域网监听和连接，不删除工作区数据。

启用接入后可以关闭受控端窗口。退出 Daban、注销或休眠会影响桌面连接；若需要开机后接入，在系统登录启动项中启动 Daban。系统锁屏 / 休眠事件、回到 Daban 或 Ctrl+Alt+Escape 会暂停原生操作；Linux 锁屏联动尚未完成实机验收。

## 兼容性和当前边界

- 旧测试版链接不兼容本次局域网协议；更新两端软件后重新复制链接。已有设备身份、模型、文件和工作区数据保留。旧连接记录会提示重新添加。
- 网络范围限可互访的 IPv4 局域网。首次配对通过复制链接完成，当前不提供自动发现、账户或短数字连接码。
- 公网接入、外部 Connect / TURN 服务及云端无人值守部署不属于首版。
- macOS / Windows 复用既有原生驱动；Linux 仅 X11，当前 Linux 原生二进制为 x86-64，Wayland 不支持。
- 自动化验证使用合成内容。两台真实设备的网络与原生输入仍需在对应设备验收。

## 开发验证

`npm run test:remote` 验证真实 TLS 业务连接和合成视频。其本地 coturn 仅用于合成视频测试，客户端运行不依赖 coturn。`npm run dev:web` 后访问 `/preview/remote.html` 可查看合成界面，使用 `lang=en`、`theme=dark` 检查其他语言和主题。
