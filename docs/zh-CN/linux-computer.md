# Linux 电脑与人工接管

[使用文档](README.md) · [English](../en/linux-computer.md)

适用：配有本地 Linux 环境的 Apple 芯片 Mac。Windows 当前提供[本机桌面](local-computer.md)，不提供这套独立 Linux 桌面。

## 连接 Bot 的电脑

1. 选择 Bot，打开对话顶部的「电脑」面板。
2. 选择「Linux 虚拟机」，点击「连接电脑」。任务正在执行或运行环境待恢复时，先按界面提示处理。
3. 等待连接成功，查看 Linux 桌面或浏览器画面。
4. 向 Bot 交代需要图形界面的工作；普通计算、文件处理可直接使用工作区工具，不必打开终端窗口。

可连接的电脑数量以界面显示的名额为准。没有电脑连接的 Bot 仍能聊天；未确认回收的电脑资源可能继续占用名额。

## 接管与交还

点击「接管电脑」后，Bot 暂停对这台电脑的操作，你可以点击、键入、拖动窗口，使用终端、文件管理器、编辑器及浏览器。需要更大空间时点击展开图标。

完成操作后点击「交还给 Bot」。只切换到另一位 Bot 不会自动交还这台电脑；其他 Bot 的独立屏幕可继续工作。查看画面时未接管，属于只读状态。

远程画面获得焦点后，Escape 返回客户端；需要把 Escape 发送给远端应用时使用 Alt + Escape。输入区也可用于发送组合输入法文字。

## 共用什么、独立什么

每位 Bot 有自己的屏幕、窗口和浏览器标签；它们共用 Linux 系统、工作文件、软件和浏览器登录。退出账号、删除共享文件或修改系统可能影响其他 Bot。独立屏幕不是 Bot 之间的安全边界。

Bot 在 VM 内可以使用网络、sudo 和系统工具；模型密钥、DSH 和审批保存在 VM 外。默认不把宿主机目录直接挂入 VM。文件交换见[文件](files.md)，安装应用见[软件安装](software.md)。

## 停止或异常恢复

先保存应用中的内容，再停止该 Bot 的电脑。停止电脑不等于删除 VM 或已保存文件。结果不明时先核对；必要时使用[恢复整个环境](recovery.md)，这会影响所有 Bot 的 Linux 桌面。
