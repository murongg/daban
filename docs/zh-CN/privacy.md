# 隐私、数据范围与权限

[使用文档](README.md) · [English](../en/privacy.md)

Daban 当前以本机运行和你选择的模型连接为基础，不要求购买 Daban 的托管云主机。本地保存不等于内容永远不离开电脑：使用远程模型或外部服务时，相关输入会发送到所配置的目标。

## 数据去哪里

| 内容 | 范围 |
| --- | --- |
| 聊天、选用资料、图片与工具结果 | 按任务需要进入所选模型请求 |
| 本机桌面截图 | 授权后可能包含主显示器上的真实应用和内容，发送给所选模型 |
| 模型密钥、DSH 和审批 | 保存在 VM 外的本机后台，不作为普通 VM 文件交给 Bot |
| 公开网页读取 | 匿名访问目标网址，不携带共享浏览器的登录 Cookie |
| 浏览器操作 | 使用 Linux 共享浏览器或本机真实应用的现有状态 |
| MCP 参数与返回内容 | 在所选外部服务及相关模型处理范围内 |

不要把密码、API Key 或令牌写进职责、记忆、技能或普通聊天。配置凭据应使用专门表单；导出包也可能包含业务资料，分享前要检查。

## 两种电脑的权限

Linux 模式里，Bot 可以完整管理 VM，包括网络、sudo、软件与文件；宿主机目录默认不直接挂载。多 Bot 共用系统、文件和登录，独立屏幕不构成相互安全隔离。

本机桌面控制操作当前用户的真实电脑。在 macOS 和 Linux 上，选择[完全访问权限](approvals.md)还可让任务命令直接以当前账号运行，使用该账号的文件和网络权限。管理员权限、安全桌面和其他受保护界面仍由操作系统管理。

## 授权如何变化

- VM 命令审批通常针对一次具体操作。
- 本机授权针对 Bot、模型和当前控制会话；断开、退出或配置变化可能使其失效。
- 外部工具按 Bot 和当前工具目录保存选择，实际调用仍需审批。
- 导入、复制、恢复归档不会自动恢复所有旧工具或电脑权限。

## 清理与保留

清空当前偏好不删除旧聊天和历史版本；归档也不是永久删除。永久清理附件可能使历史引用失效。工作区 JSON 不是完整数据库、原件或 VM 备份，详见[数据保留](workspace-export.md)。

当前没有内置多人账户隔离、手机同步或自动云备份的保证。对需要不同账号或数据安全边界的工作，不要仅凭 Bot 名称、分组或独立屏幕区分权限。
