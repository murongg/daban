# 工作区导出与数据保留

[使用文档](README.md) · [English](../en/workspace-export.md)

入口：**设置 → 数据与存储 → 导出工作区**。下载的是客户端工作区的 JSON 副本，不是整套软件的完整备份。

## 导出步骤

1. 先保存重要表单与正在编辑的内容。
2. 打开设置的数据与存储页面，点击导出。
3. 将 `daban-workspace.json` 保存在你能找回的位置。
4. 按实际内容检查分享范围；不要直接把导出文件公开提交到 Git。

## 包含与不包含

| 内容 | 工作区导出 |
| --- | --- |
| 客户端私聊缓存、草稿、偏好与设置 | 包含已保存到客户端的部分 |
| 附件引用 | 可包含引用，不等于原件 |
| 后台完整群聊记录、资料库与数据库 | 不包含完整副本 |
| 附件原件、Linux 工作产物和 VM 磁盘 | 不包含 |
| API Key 与本机电脑控制授权 | 不作为可迁移授权导出 |

当前不能把该文件当作一键还原所有历史、账号和运行环境的保证。客户端也没有完整环境的一键导入恢复流程。

## 真正需要保留的数据

重要产物应从[文件面板](files.md)下载；资料正文和原件分别在[资料库](knowledge.md)下载；可分享的 Bot 内容使用[Bot 导出](bot-transfer.md)。完整后台和 VM 的备份需要单独规划，不能只依赖这个 JSON。

卸载、清空用户目录、删除 VM 或“重新初始化”可能失去后台记录、登录和文件。先确认保留范围，再处理环境问题。不要把清理可重建安装产物与删除用户工作环境混为一谈。

目前导出用于留存和检查，不提供跨设备实时同步、手机上下文同步或自动云备份。
