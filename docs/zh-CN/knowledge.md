# 资料库与文档版本

[使用文档](README.md) · [English](../en/knowledge.md)

入口：Bot 工作区的 **资料** 面板。资料库属于这位 Bot，用于长期保留参考材料；群聊目前没有独立的公共资料库，可选择具体成员查看。

## 新建、导入和查找

1. 点击「新建资料」填写名称和正文，或点击「导入资料」选择文件。
2. 可使用 UTF-8 的 Markdown、TXT、CSV、JSON。可用 Linux 工作区还可提取 PDF、DOCX、XLSX、PPTX 的文本。
3. 检查导入结果，再让 Bot 基于指定资料回答。
4. 在「查找资料」中按关键词搜索，打开文档查看完整内容。

每份文本正文最多 200 KiB；原件上传上限为 5 MiB。扫描件需先 OCR，加密文件需先解密。Windows 本机模式当前不能解析 PDF 和 Office。

## 原件与文本快照

导入保存的是文本快照。源文件之后被修改，不会自动同步到资料库；重新导入或明确更新正文后才会变化。

PDF/Office 原件与提取正文分开保留。修改正文不会修改原件；图片、排版、图表和公式不作完整还原。可分别下载已保存正文和保留的导入原件，注意两者内容可能不同。

## 修改、删除与恢复

打开文档编辑并保存。出现版本冲突时，核对后台当前内容再决定如何保存。

通过「版本历史」查看保留版本；恢复旧版会创建新的当前版本，而不会抹去中间更改。移入回收站保留版本历史，可从保留的非删除版本恢复。

## 让 Bot 使用资料

例如：“读取资料库中那份项目说明，引用具体段落回答，不要只根据标题推断。”Bot 可查询和读取资料；不能假定每次任务都会把整套资料库全文放进上下文。

目前没有文档源自动同步、通用 OCR 或完整语义向量检索的保证。资料是参考内容，不授予新权限；被读取的内容可能发送给所选模型服务。需要随 Bot 分享时见[导入导出](bot-transfer.md)。
