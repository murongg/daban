# 创建与管理 Bot

[使用文档](README.md) · [English](../en/bots.md)

Bot 是长期保留的工作搭档。它有独立的资料、私聊、工作偏好、资料库、便笺和定时任务；它不是一台独占的虚拟机。

## 创建

1. 点击侧栏顶部的「新建 Bot」或「你的 Bot」旁的加号。
2. 填写名称，选择头像颜色，说明职责；也可以从 [Bot 广场](gallery.md)开始。
3. 选择跟随工作区模型，或指定已配置的模型。
4. 保存后进入对话。需要图形界面时，再连接电脑。

职责建议写清楚目标、输出要求和工作方式，例如：“帮助整理业务资料；先列结论和来源；不确定时先问我。”职责说明不会授予新的工具或电脑权限。

## 修改

打开 Bot 对话右上方的「编辑 Bot 资料」，修改名称、职责和模型。模型和职责修改用于后续任务，不会改变已经开始的任务。头像颜色用于区分搭档，不代表工具能力等级。

不同客户端或 Bot 同时修改同一份资料时，可能出现版本冲突。先查看当前保存内容，再选择保留自己的修改并重新保存，不要直接覆盖未核对的更新。

## 不同的复制与保留方式

- 想用相同职责创建另一位搭档：使用[复制 Bot](copy-bot.md)。
- 想分享选定的资料、偏好和技能说明：使用[Bot 导入导出](bot-transfer.md)。
- 想暂时收起 Bot：使用[归档](archives.md)，而不是清空聊天或删除运行环境。

Bot 名称相同不代表同一身份。复制和导入生成新 Bot；新 Bot 不会继承原 Bot 的聊天或电脑授权。

## 数据和电脑的边界

私聊、记忆和资料分别属于各自的 Bot；[共享任务](tasks.md)属于整个工作区。Linux 模式下，文件、已安装软件和浏览器登录由 Bot 共用，独立屏幕不等于安全隔离。详见[隐私与权限](privacy.md)。
