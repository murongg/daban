## 平台差异速查

| 能力 | Apple 芯片 Mac 的 Linux 模式 | Mac / Windows 本机模式 |
| --- | --- | --- |
| 聊天、Bot、记忆、资料文本、便笺和共享任务 | 支持，需相应后台与模型 | 支持，需相应后台与模型 |
| 多 Bot 独立 Linux 屏幕 | 支持，以电脑名额为准 | 不提供；本机同一时间一位 Bot |
| Linux 命令、长进程和共享软件 | 支持 | 不提供同等程序化工具 |
| PDF / Office 文本提取 | 支持 | Mac 需有可用 Linux 解析能力；Windows 当前不提供 |
| 真实主机应用 | 需切换本机控制并授权 | 主显示器、当前用户权限 |

功能以实际客户端和后台能力为准。当前没有托管云主机、手机端或跨设备实时同步；保存待办不等于开始执行，导出 JSON 不等于完整备份。源码开发见[开发指南](../development.md)。
