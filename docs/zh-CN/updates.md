# 应用更新

正式安装的 macOS Apple 芯片版和 Windows x64 安装版可在「设置 → 关于」检查稳定版更新。启动后也会自动检查；发现新版本时只提示，不会自动下载大安装包或打断任务。

## 下载和安装

1. 点击「检查更新」，查看版本和更新内容。
2. 点击「下载更新」。可以取消下载，失败后可以重试；取消不影响当前版本。
3. 保存尚未提交的设置，以及电脑应用中未保存的内容。
4. 点击「重启并安装」，确认后继续。工作区聊天草稿会在安装前再保存一次。

后台有 Bot 任务、环境安装、恢复或其他操作时，更新不会强制停止它们。完成这些操作后再次安装即可。保存工作区失败也会取消重启，可先导出工作区。

更新会正常退出空闲的后台服务并重启客户端，不会删除虚拟机、工作文件、模型配置或聊天数据库。Linux 虚拟机保留，电脑连接可能暂时断开。更新前请保存外部应用中的内容。

## 支持范围

- macOS：带在线更新配置的 Developer ID 签名发行版。ZIP 中的应用和 DMG 均经过公证。
- Windows：标准安装器安装的 x64 版本，安装在当前用户目录。便携 ZIP 不进行原地自动替换，请改用安装版。
- 开发模式、网页预览和旧临时签名原型不提供在线安装，首次需要手动安装支持更新的新客户端。

更新来自项目的 GitHub Releases，下载会验证完整性，macOS 还会验证应用签名。检查更新不调用模型 API，也不发送聊天或工作文件。尚未发布正式客户端时，会显示暂无稳定版可用。
