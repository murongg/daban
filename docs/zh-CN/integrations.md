# 外部工具与 MCP 连接

[使用文档](README.md) · [English](../en/integrations.md)

在 **设置 → 外部工具** 管理账号和 MCP 连接；在目标 Bot 的 **能力 → 外部工具** 为它启用工具。添加连接时无需选择 Bot。

## 添加和检查连接

1. 在设置中选择「自定义远程 MCP」（旧 Host 为「添加连接」），填写名称与服务 URL。
2. 服务需要鉴权时，填写 Bearer Token。
3. 保存后点击「检查连接」，读取当前工具目录。
4. 进入目标 Bot 的「能力 → 外部工具」，打开对应连接的「工具与授权」，选择工具并保存。

当前支持公网 HTTPS 的 Streamable HTTP。启动本地程序、stdio 接入、自定义请求头等方式尚未提供。不要把供应商的普通模型 API 地址误当作 MCP 服务地址。

点击「连接 Linear、Sentry、Todoist、Miro 或 monday.com」，在系统浏览器中授权；连接名默认使用应用名称，同名时自动编号。已有账号时，先展开「添加应用」。monday.com 自定义客户端需要在官方页面获得管理员批准，等待批准不会显示为账号已连接。授权后仍须分别检查连接、选择工具并启用。**Notion 连接功能暂未开放。** OAuth 需要本机 Electron／Host 回调；远程目标可查看状态和使用自定义 Bearer，不能发起本机 OAuth。较旧的运行环境可添加自定义 MCP；应用账号连接需要更新运行环境。

OAuth 凭据只保存在 Host 私有存储。普通刷新保留已审阅的连接版本；重新授权或 scope 变化后须重新检查工具。取消只影响本次授权事务；断开会清除本地 Token 并失效旧绑定，供应商端撤销标为未确认。Token 交换、刷新和已派发工具调用的结果不明时均不会自动重放。关闭窗口不停止已接受任务。

编辑已有连接时，地址和 Token 不会完整回显；按界面说明留空保留，清除 Token 需明确勾选对应选项。修改目标和凭据后要重新检查授权。

新连接可供多个 Bot 各自启用工具，默认不会向任何 Bot 开放工具。可以为同一服务添加多个账号。已有私有连接仍只供原 Bot 使用，已有工具授权保持原样。

## 每位 Bot 单独授权

选择工具并保存，只表示新任务可使用这份选择。实际每次调用仍需本次审批，应核对工具名、参数、目标连接和副作用。连接成功也不会自动把全部工具交给所有 Bot。

工具目录、授权或连接版本变化后，原选择可能失效。重新检查并审阅当前目录，再保存启用；不要根据旧工具说明盲目继续。

## 结果、回执和停用

「最近调用」展示这位 Bot 在该连接上的最近 20 次调用，可查看参数、返回内容和回执。查询回执不会重新执行工具。

停用会取消尚未发出的调用；已经发出的请求可能已在外部系统生效。结果不明时先核对回执和服务状态，不要直接重发。

归档 Bot 自己的连接只影响这位 Bot，恢复后需重新选择工具并启用。在设置中归档共享连接或断开账号会停用使用该连接的所有 Bot，操作前会列出受影响的 Bot。工具说明与返回内容不会授予额外权限。参数和结果会进入相关服务及模型处理范围，见[隐私与权限](privacy.md)。
