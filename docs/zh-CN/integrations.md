# 外部工具与 MCP 连接

[使用文档](README.md) · [English](../en/integrations.md)

入口：当前 Bot 的 **能力 → 外部工具**，也可在 **设置 → 外部工具** 先选择 Bot。MCP 连接把外部服务的工具接入 Bot，不等同于模型供应商连接。

## 添加和检查连接

1. 确认当前 Bot，点击「添加连接」，填写名称与服务 URL。
2. 服务需要鉴权时，填写 Bearer Token。
3. 保存后点击「检查连接」，读取当前工具目录。
4. 打开「工具与授权」，为这位 Bot 选择要开放的工具，勾选允许使用并保存。

当前支持公网 HTTPS 的 Streamable HTTP。启动本地程序、stdio 接入、OAuth 登录、自定义请求头等方式尚未提供。不要把供应商的普通模型 API 地址误当作 MCP 服务地址。

编辑已有连接时，地址和 Token 不会完整回显；按界面说明留空保留，清除 Token 需明确勾选对应选项。修改目标和凭据后要重新检查授权。

新连接、账号凭据与工具选择属于选定 Bot。同名服务可以为不同 Bot 配置不同账号；不会自动共享 Token。旧共享连接会保留并标明，若要独立管理，请在该 Bot 下创建连接并重新填写服务地址与凭据。

## 每位 Bot 单独授权

选择工具并保存，只表示新任务可使用这份选择。实际每次调用仍需本次审批，应核对工具名、参数、目标连接和副作用。连接成功也不会自动把全部工具交给所有 Bot。

工具目录、授权或连接版本变化后，原选择可能失效。重新检查并审阅当前目录，再保存启用；不要根据旧工具说明盲目继续。

## 结果、回执和停用

「最近调用」展示这位 Bot 在该连接上的最近 20 次调用，可查看参数、返回内容和回执。查询回执不会重新执行工具。

停用会取消尚未发出的调用；已经发出的请求可能已在外部系统生效。结果不明时先核对回执和服务状态，不要直接重发。

归档 Bot 自己的连接只影响这位 Bot，恢复后需重新选择工具并启用。设置中对已有共享连接进行归档仍会影响所有使用它的旧绑定，界面会单独提示。工具说明与返回内容不会授予额外权限。参数和结果会进入相关服务及模型处理范围，见[隐私与权限](privacy.md)。
