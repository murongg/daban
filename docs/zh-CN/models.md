# 模型与供应商

[使用文档](README.md) · [English](../en/models.md)

入口：**设置 → 模型与供应商**。首次使用时也会显示模型配置引导。

## 准备 API Key

在所选供应商的官方控制台，按其指引开通 API 并创建密钥，再填入 Daban 的专用表单。网页聊天订阅与 API 额度可能分别管理，具体以供应商账户为准。不要把密钥发给 Bot 或贴到问题反馈中。

## 添加连接和模型

1. 点击「添加供应商」，选择平台预设或自定义接口。
2. 核对接口协议与 API 地址。预设只是填写常用地址；地区、网关和账户专属地址需要自行调整。
3. 填写该连接的 API Key。不同连接分别保存密钥，不会因为显示名称相同而共用。
4. 点击「加载模型列表」，搜索并选择模型；供应商不提供列表时可手动填写准确的模型 ID。显示名称可以自行修改。
5. 新增或修改模型 ID 后，客户端会自动参考 models.dev 匹配上下文和图片能力。已有模型可点击「匹配模型能力」。供应商明确返回的上下文限制优先于公共目录。
6. 点击「测试模型」检查一次真实的短文本调用，再点击「验证并保存供应商」。读取模型列表不等于模型调用成功；测试和保存验证可能产生少量 API 费用。

模型测试使用固定的短提示，不发送你的聊天内容，也不会自动保存表单。自动参考公共目录匹配能力本身不会调用模型。

## 协议如何选择

| 连接类型 | 选择与地址要求 |
| --- | --- |
| OpenAI 兼容服务 | 使用服务商支持的 Chat Completions 或 Responses，不能只凭名称判断 |
| Claude 原生接口 | 选择 Claude Messages，填写服务根地址，不额外添加 `/v1/messages` |
| Gemini 原生接口 | 选择 Gemini GenerateContent，默认地址包含 `/v1beta` |

常用平台包括 OpenAI、Claude、Gemini、Grok、DeepSeek、千问、Kimi、智谱、MiniMax、豆包、硅基流动、OpenRouter、混元、千帆、Groq 和 Together AI。预设存在不代表所有平台功能都已接入；Azure 部署、AWS Bedrock 等额外鉴权方式尚未提供。

## 模型能力和上下文

- Bot 执行任务需要模型支持工具调用。展开「模型能力」可查看目录中的输入/输出类型、推理、工具调用、结构化输出和温度支持声明。
- 模型名称旁用图标显示文本、图片、音频、视频、PDF 输入能力，悬停可查看含义。编辑时点击图片图标开启或关闭图片输入与桌面观察；自动匹配后仍可手动调整，未匹配到或存在冲突的能力不会凭名称猜测。
- 模型系列图标按模型 ID 识别；供应商标识仍来自所配置的 API 地址。通过自定义供应商连接 GPT 时，可以显示 OpenAI 系列图标，但连接仍由该供应商提供。
- 音频、视频、原生 PDF 等目录声明目前仅供参考。PDF/Office 的文本提取见[附件](attachments.md)，不等于直接把 PDF 作为原生模型输入。
- 上下文窗口决定可容纳的输入与输出规模；输出上限是单次回复预算。不要把公共目录的最大值当成当前账户或网关保证提供的额度。
- 短文本测试不能证明图片、工具调用或所有长上下文场景均可用。

## 工作区默认与 Bot 专属模型

设置中的「工作区默认模型」供选择「跟随工作区」的 Bot 使用。单个 Bot 可在资料中另选模型。修改从下一次任务生效；正在运行的任务继续使用原连接。

编辑已有连接时，Key 留空可保留同一地址、同一协议的密钥；修改地址或协议需重新填写。保存结果不明时先核对原请求，不要不断创建新连接重试。

联网搜索另有配置条件，见[网页调研](web.md)。API Key 不要写进聊天、技能、导出包或 Git。
