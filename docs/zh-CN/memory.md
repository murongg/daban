# 工作记忆与偏好

[使用文档](README.md) · [English](../en/memory.md)

入口：选择一位 Bot，打开 **记忆** 面板。这里保存它长期使用的工作偏好，与聊天历史和资料库不同。

## 记忆如何生成

当前不会把所有对话自动提炼成长期记忆。你可以直接编辑保存，也可以明确对 Bot 说“记住这个偏好”“修改这条偏好”或“忘掉某条偏好”。Bot 的记忆工具与面板编辑的是同一份内容。

适合保存：“答复先给结论，再列依据”“金额统一注明币种”。不适合保存：整篇报告、临时网页内容、未经核实的推断、账号密码或 API Key。

## 编辑与应用

1. 打开记忆面板，查看当前工作偏好。
2. 编辑完整内容，保存记忆。
3. 需要通过对话修改时，明确指出保留、修改或删除哪一条，并让 Bot 读回核对。
4. 下一次任务使用最新保存的偏好；正在执行的任务不会因此改写已经使用的上下文。

每位 Bot 的偏好分别保存；群聊成员也各自保留记忆。资料和网页中的文字不应自动变成偏好或工具授权。

## 历史版本

打开「历史版本」，查看旧内容；选择载入只是填入编辑器，确认保存后才会更新当前偏好。历史内容不会自动全部发送给模型。

最多保留最近 50 个版本，长内容可能降低实际保留数量。清空当前记忆不会删除旧聊天或已经保留的记忆历史，不能把清空输入框当作完整的数据擦除。

## 冲突和异常

如果 Bot 与你同时更新，先核对最新版本。保留无关偏好，避免整段覆盖造成丢失。结果待确认时先查原操作，不要重复写入。

需要存长篇原文时用[资料](knowledge.md)，零散事项用[便笺](notes.md)，跨 Bot 跟进用[共享任务](tasks.md)。
