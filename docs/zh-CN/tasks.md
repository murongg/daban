# 共享任务与看板

[使用文档](README.md) · [English](../en/tasks.md)

入口：侧栏 **任务**。这里是所有 Bot 和你共用的持久待办，与当前聊天的一次执行计划不同。

## 新建任务

1. 点击「新建任务」，填写标题、任务说明和最新进展。
2. 选择状态并保存。
3. 若要 Bot 实际处理，再到对话里明确要求它读取并执行这张任务。
4. 检查实际结果后，更新进展和状态。

也可以说：“把这件事记录成共享待办，暂不执行。”保存、修改状态、评论或指定完成都不会自动运行 Bot。

## 列表、看板和状态

使用关键词搜索，按全部、未完成、已完成或回收站筛选。列表与看板展示同一份数据；回收站使用列表。条目多时继续加载，已载入数量不等于总数量。

新版服务支持待处理、进行中、待审核、受阻、已完成、已关闭等状态，旧版本可能仅显示基础三种。状态是工作记录：标为完成或关闭，不代表程序已运行或产物已验证。

## 协作与讨论

Bot 可以在得到明确任务后读取、记录进展和更新共享待办。需要补充说明时，打开「查看讨论」，见[任务评论](comments.md)。待办的正文和讨论不能自行成为执行授权。

## 草稿与版本冲突

未保存编辑可保留在本机。后台有新更改时，先查看当前说明和进展；可以保留自己改过的字段，让未修改字段采用后台值，再核对保存。

提交结果不明时，先核对原操作。重新打开页面主要是读取结果，不应为了“确认”而重复创建任务。

## 回收站与恢复

移入回收站保留内容，可恢复后继续编辑。移入回收站不会停止一个已经在执行的 Bot 任务，也不删除它产生的文件。要停止运行，使用[停止任务](execution.md)。
