# 定时任务

[使用文档](README.md) · [English](../en/schedules.md)

入口：选择一位 Bot，打开 **定时** 面板。到时间后，后台为这位 Bot 提交任务，结果回到它的对话。

## 创建计划

1. 新建定时任务，填写名称和完整执行指令。
2. 选择单次、每天、工作日、每周五、自选每周日期、间隔或 Cron。
3. 填写日期、时间、间隔或表达式，并核对时区，例如 `Asia/Shanghai`。
4. 查看接下来触发的时间，保存并检查是否启用。

例如：“每个工作日 18:00，根据我提供并保留的工作记录整理摘要；缺少记录时说明，不编造。”计划只能使用届时实际可用的模型、资料、网络和工具授权。

## 启用、暂停、锁定

- 启用开关决定计划是否继续触发。
- 锁定主要用于保护计划不被随意修改，不等于暂停执行；Bot 不能替你解除人工锁定。修改锁定计划时先手动解锁。
- 「立即运行」提交一次任务；Bot 忙碌时可能等待可用后再开始。
- 编辑频率、启停计划或移除计划时，应检查待处理触发和最近记录，不要假定会撤回已开始的外部操作。

## 查看结果

在计划的「最近触发」查看等待、运行、完成、失败、中断、撤销等状态，再打开 Bot 对话检查结果。等待合并不代表每个错过的时间点都会补跑一次。

保存结果不明时先核对同一次请求，避免重复建立计划。每次实际执行都可能调用模型并产生费用，建议从较长间隔开始。

## 运行条件

这是本地后台调度，不是云端定时服务。执行电脑需要保持开机、唤醒、联网且后台可用；休眠和关机期间无法持续执行。退出客户端后，后台可继续，但新的桌面提醒不会被客户端发现，本机桌面授权也已撤销。

需要图形操作的计划还受电脑连接、名额及授权限制。归档 Bot 会暂停相关自动工作；恢复后需检查并手动重新启用。群聊定时任务目前不可用。
