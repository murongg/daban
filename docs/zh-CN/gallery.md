# Bot 广场

[使用文档](README.md) · [English](../en/gallery.md)

入口：侧栏 **Bot 广场**。广场提供职责预设，帮助你从一个明确用途开始，而不是预先塞入示例聊天。

支持模板版本的客户端还提供“模板来源”：添加官方或自建广场、预览并安装明确版本，或导入离线 v3 模板包。服务器可直接部署到 Cloudflare Workers/D1/R2，也可私有部署，见[独立部署 Bot 广场](gallery-deployment.md)。

## 发布与更新模板

保存 Bot 资料后，在“模板与版本”填写版本号、简介、授权说明、更新说明和默认工作方式，核对技能与预置资料后下载或发布。默认工作方式单独填写，不自动带入个人记忆。首次下载或发布后，相同版本的内容固定，变更内容需要新版本号。

已安装模板的 Bot 会记录来源和版本。检查更新后先预览差异，职责、技能和资料有冲突时逐项选择保留本地或采用新版；配置历史可预览回滚。个人记忆、模型和权限保留，新增或变化技能默认停用。关闭窗口不终止服务端任务；结果不确定时使用保留的核对入口。

## 使用预设

1. 按名称或用途搜索，或浏览分类。
2. 打开预设详情，查看职责和示例开场任务。
3. 点击「使用这个 Bot」，创建独立的新 Bot。
4. 根据实际工作调整名称、职责与模型，然后发送自己的任务。

当前包含通用助手、研究员、写作搭档、数据分析、浏览器助手、翻译、产品、内容、办公、编程、学习和灵感等方向。分类和预设文案可随版本调整，以客户端实际列表为准。

## 预设包含什么

预设主要设置名称、颜色、职责和开场建议。它不会自动连接电脑、登录网站、安装软件、配置模型密钥或启动任务。带有“浏览器”“编程”等名称，也不代表已经取得相关权限。

添加同一种预设可以得到多位独立 Bot。之后修改某位 Bot 的职责，不会同步修改其他副本。预设内容是起点，真正适合你的长期行为应在[职责](bots.md)、[工作记忆](memory.md)或[技能](skills.md)中调整。

没有合适的预设时，直接[创建 Bot](bots.md)，无需先选一个近似的用途。
