# 快捷键与图标

[使用文档](README.md) · [English](../en/shortcuts.md)

快捷键按当前焦点与平台生效。打开弹窗、编辑器或远程电脑后，按键可能由当前控件处理。

| 操作 | Mac | Windows |
| --- | --- | --- |
| 搜索 Bot 和对话 | Cmd + K | Ctrl + K |
| 打开设置 | Cmd + , | Ctrl + , |
| 发送消息 | Enter | Enter |
| 消息换行 | Shift + Enter | Shift + Enter |
| 退出远程画面输入焦点 | Escape | Escape |
| 向远端发送 Escape | Option / Alt + Escape | Alt + Escape |
| 暂停真实本机电脑控制 | Ctrl + Option + Esc | Ctrl + Alt + Esc |
| 打开 Bot 行整理菜单 | 菜单按钮；有焦点时 Shift + F10 | 菜单按钮；有焦点时 Shift + F10 / 菜单键 |

工作区中的 Escape 也可关闭侧栏或工作区面板，多数弹窗可用 Escape 退出。提交中或待确认的操作以界面提示为准；关闭弹窗不会撤回动作。

## 常见图标

- 方形停止图标：请求停止当前任务，不是删除记录。
- 对角展开图标：扩大电脑或浏览器视图。
- 刷新图标：重新读取当前列表或状态，不代表重跑历史任务。
- 省略号或整理按钮：打开当前 Bot、群聊或分组菜单。
- 锁图标：定时计划的修改保护，不是启停开关。

鼠标悬停或键盘聚焦可查看多数图标提示。输入中文等语言时，先完成输入法选词再发送。远程画面无法正确输入时，可使用其文字输入区，而不是持续重复按键。

暂停桌面、停止模型任务、停止 Bot 电脑和恢复整个 Linux 是不同操作，分别见[本机控制](local-computer.md)、[执行过程](execution.md)、[Linux 电脑](linux-computer.md)和[环境恢复](recovery.md)。
