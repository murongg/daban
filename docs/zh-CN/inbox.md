# 收件箱

[使用文档](README.md) · [English](../en/inbox.md)

入口：侧栏 **收件箱**。这里集中显示真实任务需要你回答或确认的事项。

## 处理待办请求

1. 打开待处理列表，核对请求来自哪位 Bot、哪次任务。
2. 展开详情，查看问题、命令、安装计划、网址或外部工具参数。
3. 填写答案，或选择允许、确认、拒绝。
4. 提交后查看已处理状态，再回到 Bot 对话观察是否继续执行。

点击桌面通知进入时，可能会定位到某一条请求；可选择「查看全部」返回完整列表。

## 看懂不同状态

- 等待回答：Bot 需要补充信息。
- 等待确认：需要一次操作许可。
- 已回答、已允许或已拒绝：代表这份请求处理完毕，不代表整个任务一定成功。
- 已撤销或任务中断：旧请求不再能提交。

提交结果未确认时，先检查连接并使用原请求的核对/重试入口。不要因为没有立即看到反馈而再次创建相同操作。

## 收件箱和其他入口

收件箱主要用于待处理问题与审批。普通任务结果应到 Bot 会话或[历史对话](conversations.md)查看；需要所有 Bot 共用的工作清单在[任务](tasks.md)中。

不想漏掉后台请求，可配置[桌面提醒](notifications.md)。提醒只是入口，最终状态以实际请求与执行结果为准。
