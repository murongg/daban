# 复制 Bot

[使用文档](README.md) · [English](../en/copy-bot.md)

入口：侧栏 Bot 行的整理菜单 → **复制 Bot**。适合用同一套职责再创建一位独立搭档。

## 操作步骤

1. 选择一位可用、未归档的个人 Bot，打开复制入口。
2. 查看来源的已保存资料，填写新名称。
3. 选择是否复制已保存的工作偏好。
4. 确认创建，再打开新 Bot 核对职责和模型。

复制基于已经保存的内容；来源编辑器中尚未保存的文字不在复制范围。来源变更时先载入最新内容再核对，新名称和偏好选择会保留。

## 复制范围

| 会复制 | 不会复制 |
| --- | --- |
| 已保存职责、颜色、模型选择 | 聊天与历史上下文 |
| 你选择包含的工作偏好 | 定时任务、电脑控制或外部工具授权 |
| 独立的新 Bot 身份 | 浏览器登录或一台专属 VM |

资料与技能需通过[Bot 导入导出](bot-transfer.md)另行迁移。Linux 文件和浏览器仍遵守整个运行环境的共享规则。

## 结果待确认

先查看复制进度或核对结果。重试原请求不会故意再创建第二位 Bot；不要为同一次复制反复开新请求。关闭弹窗不能撤回已提交的创建。

复制完成后，修改新 Bot 的职责和记忆不会改动来源；但共享软件、文件、技能库等仍不是彼此隔离的。两位 Bot 可分别配置模型和工具权限。
