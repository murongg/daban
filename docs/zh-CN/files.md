# 工作区文件与预览

[使用文档](README.md) · [English](../en/files.md)

入口：Bot 工作区的 **文件** 面板。这里查看实际保留的工作文件，与聊天附件和资料库各有用途。

| 内容 | 用途 |
| --- | --- |
| 工作区文件 | 任务生成或需要继续处理的文件；Linux 环境中存在共享区域 |
| 聊天附件 | 本次消息的输入材料及已保留的附件 |
| 资料库 | 某位 Bot 长期保存的文本参考材料 |
| 本地文件夹 | 你连接给当前 Bot 的真实电脑目录；直接搜索、编辑或整理原文件 |

## 连接本地文件夹

1. 点击聊天输入框旁或文件面板中的 **本地文件夹**，选择 **添加文件夹**。
2. 在系统目录选择窗口中选中需要处理的目录。连接仅属于当前 Bot，可连接多个目录。
3. 也可以直接把本机目录路径或 `file://` 链接发给 Bot。如果目录尚未连接，Bot 可以申请访问；你需要在系统目录选择器中确认实际目录。申请中的路径只用于定位选择器，最终只有你选中的目录会被连接。
4. 告诉 Bot 具体任务，例如：“搜索这个目录中提到预算的文本文件，把项目说明里的状态改成已确认，再读取结果检查。”无需启动 Linux。
5. 在同一窗口查看最近文件变更。较短文本会保留修改前后内容；删除的普通文件进入原目录内的 `.daban-trash`，可选择 **恢复文件**。恢复不会覆盖同名文件。
6. 选择 **断开** 撤销后续访问，原文件保持不变。重新连接同一实际目录后，可以继续恢复该目录中的删除记录。

Bot 可以列目录、读取 UTF-8 文本、按文件名模式或字面内容搜索、创建及精确编辑文本文件、创建目录、移动或重命名普通文件，以及移入 Daban 回收站。已有文件的修改使用读取时的版本，防止覆盖之后的人工修改；“每次询问”模式会在本地修改前展示操作批准卡。

连接文件夹还可为 `local_shell` 提供本机命令行处理能力，适合用已安装的 Python、Node 或其他本机工具处理复杂文件。每条命令都单独要求确认，批准卡会显示完整命令、执行目录和授权文件夹；命令在沙箱中运行，只能访问该文件夹及系统工具，没有网络或 sudo 权限。若系统沙箱组件不可用，命令会拒绝执行。此能力支持 macOS 和 Linux，不会把文件自动传入 Linux 虚拟机。

文本读写单文件上限为 1 MiB；二进制文件可列出、移动和回收。搜索跳过链接、`.git`、`node_modules` 和 Daban 回收站；结果达到限制时应缩小搜索范围。最近变更最多显示 100 条，操作结果不确定时先核对实际文件，不要重复执行。

## 查看和使用

1. 打开文件面板，刷新列表。
2. 点击文件查看可用预览；按需下载到本机。
3. 要交给模型处理时，选择加入消息，并补充处理要求。
4. 从会话中的文件结果打开内容时，也应核对当前文件，而不只看模型声称生成了什么。

例如：“根据附件生成一份 CSV，保存结果，并检查表头和行数。”任务完成后下载实际文件验证。

## 共享与路径

普通任务使用应用管理的本机工作区，可以直接列出、读取、写入文件和导出知识库文本，无需启动 VM。这些工具不能访问本机工作区之外的任意文件，也不提供宿主机 shell。

Linux 保留独立的任务目录和共享目录。需要命令或 Linux 软件时，Bot 才按需使用已安装的 Linux，并通过明确的文件交换传入其他输入、取回产物；不会把整个本机工作区自动同步进去。不同任务的目录可能不同。需要后续复用时，明确告诉 Bot 查找先前产物或共享文件，而不是猜一个旧路径。旧 Linux 文件仍保留在 Linux 中，可用 Linux 文件工具查找。

独立屏幕不隔离这些文件。覆盖、移动或删除共享文件可能影响其他 Bot。宿主机文件不会因为存在于 Mac 或 Windows 文件夹中就自动出现在 VM，需通过附件、下载或明确的文件交换流程处理。

## 当前限制

- 普通工作区工具仅限应用管理的目录；独立的本地文件工具和本机命令只访问你连接给当前 Bot 的目录。链接和应用私有数据目录不开放。本机命令每次都需批准，且仅支持 macOS/Linux；Windows 暂不开放。Linux shell 和进程使用单独的 Linux 虚拟机，实际调用时才启动。真实本机应用仍通过单独授权的本机桌面操作。
- 文件预览不替代专业软件；大型、二进制或复杂格式可能需要下载后打开。
- 历史链接引用的是仍保留的当前文件，不是不可变的完整备份。
- 「导出工作区」不包含本机及 Linux 工作文件或 VM 磁盘，重要产物请单独下载，见[工作区导出](workspace-export.md)。
