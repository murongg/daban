## Platform

web

## Stack

Electron desktop client with React, TypeScript and Vite as the renderer. The user explicitly reconfirmed Electron during this implementation. Electron main owns the allowlisted IPC and loopback HTTP connection to the adopted local Lima VM; the renderer has no Node or network access. Maintained application code, runtime and tests use TypeScript. Explicit use of the void keyword is forbidden and checked during build.

## Users

Chinese-speaking users of a general-purpose computer agent. The product is not restricted to an industry or profession.

## Product Purpose

Give each persistent Bot a conversation and shared workspace context, with an optional computer screen and explicit human takeover when connected.

## Brand Commitments

The user named the project daban and requested UI as close to Grok Bot as possible. Inherit the quiet monochrome conversation workspace from the previous local prototype and the official demo capture. No new visual direction is needed. UI copy is Chinese; brand is lowercase daban.
